# 看完笔记很失望怎么办

没关系，倘若真心想学习算法，那么接下来将给你指出几条明路：
- <img src="https://proicons.com/icon/595755.svg" alt="Codeforces icon" width="18" height="18" style="vertical-align: -0.1em;"> [Codeforces](https://codeforces.com/)，世界最大的算法练习平台，偏重于思维的训练，算法含量较少。其中难度`Div1` > `Div2` > `Div3` > `Div4`，带有`Education`的标识本场比赛比较有教育意义。倘若能做到`Div2`的D-E题左右，那么就有差不多区域赛铜牌的水平
- [AtCoder](https://atcoder.jp/home)，日本最大的算法比赛平台。
- <img src="https://proicons.com/icon/596929.svg" alt="Luogu icon" width="18" height="18" style="vertical-align: -0.1em;">[Luogu](https://www.luogu.com.cn/)，服务于中国的`OI`选手，算法和数学方面的题目很多，同时也会有部分ICPC或者CCPC赛题，里面题解选手的水平很高。
- [QOJ](https://qoj.ac/)，这个平台存有很多大部分的赛事，尤其是其中ICPC和CCPC的，近 $5$ 年全都有。
- <img src="https://proicons.com/icon/436755.svg" alt="Degree Hat icon" width="18" height="18" style="vertical-align: -0.1em;">[OI Wiki](https://oi-wiki.org/),算法学习平台。
- <img src="https://proicons.com/icon/512790.svg" alt="Brand Leetcode icon" width="18" height="18" style="vertical-align: -0.1em;">[leetcode](https://leetcode.cn/)主要服务于面试时候的算法题，算法比较简单只适用于就业面试
