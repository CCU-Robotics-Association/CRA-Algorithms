[[裴蜀定理]]说明了一次方程的存在性，而扩展欧几里得算法则是计算二元一次方程的系数的具体值
# 扩展欧几里得算法
#扩展欧几里得
我们知道，欧几里得算法（辗转相除法），即`gcd`获取两个数的最大公约数，代码如下：

```cpp
// 最大公约数
int gcd(int a,int b) {
    return b > 0 ? gcd(b, a % b) : a;
}
// 最小公倍数
int lcm(int a,int b) {
    return a/gcd(a,b)*b;
}
```

给一个辗转相除法的过程
![](资源归档/assets/33.png)

扩展欧几里得算法主要是为了解决在辗转相除的过程中求$ax + by = \gcd(a,b)$的一组解。在辗转相处的过程中我们知道一直满足以下条件$\gcd(a,b) = gcd(b,a \% b)$所以对于上面的式子，可以进化成如下式子。

$$
{\Large \begin{align}
ax+by & = \gcd(a,b) \newline
bx + (a \% b)y & = \gcd (b,a\%b)
\end{align}}
$$

开始拆解式子

$$
{\Large \begin{align}
\because  & ax+by = \gcd(a,b) \\
& bx_1 + (a \% b)y_1 = \gcd (b,a\%b)\\
& \gcd (a,b) = \gcd (b,a\%b)\\
\therefore  & ax+by = bx_1 + (a \% b)y_1    \\
\because & a \% b = a - \left \lfloor \frac{a}{b}  \right \rfloor \times b \\
 \therefore & ax+by = bx_1 + (a - \left \lfloor \frac{a}{b}  \right \rfloor \times b)y_1 \\
& ax+by =ay_1 + b(x_1 - \left \lfloor \frac{a}{b}  \right \rfloor \times y_1) \\
\therefore & 
\begin{cases}
x = y_1 \\
y = x_1 - \left \lfloor \frac{a}{b}  \right \rfloor \times y_1 \\
\end{cases}
\end{align}}  
$$

求解得出

$$
{\Large \begin{cases}
x = y_1 \\
y = x_1 - \left \lfloor \frac{a}{b}  \right \rfloor \times y_1 \\
\end{cases}}  
$$

实现代码如下：

```cpp
int exgcd(int a,int b,int &x,int &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    int d = exgcd(b,a%b,x,y),x0 = x,y0 = y;
    x = y;
    y = x0 - a/b * y0;
    return d;
}
```

那么其实在这里我们只求出了该方程的一个解，对于这样一个二元一次方程来说，应该会有无数个解才对。所以，从这个特解的基础上，我们要尝试去求出该方程的通解。

$$
{\Large \begin{align}
& 对于式子ax+by  = \gcd (a,b)\\
& 令d  = \gcd (a,b) \\
& \begin{cases}
ax + by  = d \\
ax_0 + by_0  = d\\
\end{cases} \\
& 两式相减得 \\
& a(x - x_0) + b(y - y_0) = 0 \\
& 得a(x - x_0) = -b(y - y_0) \\
& 两式同除d \\
& 得(\frac{a}{d} ) \times (x - x_0) = -(\frac{b}{d} ) \times (y - y_0) \\
& 由于d 为a与b的最大公约数\ \therefore \frac{a}{d}  \bmod \frac{b}{d}  \ne 0,即\frac{a}{d}和\frac{b}{d}互质\\
& \therefore \frac{a}{d} \bmod (y - y_0) = 0必定成立,可以改写为:y-y_0 = t \times \frac{a}{d},t\in Z,t\ne 0 \\
& 同理可得关于x的，所以整合起来得到
\begin{cases}
y = y_0 + t \times \frac{a}{d}\\
x = x_0 - t \times \frac{b}{d} \\
\end{cases} ，t\in Z,t\ne 0，d = \gcd(a,b)
\end{align}}  
$$  
上述两大式子即为方程的通解，$x_0$和$y_0$是我们求出来的特解。

其实上面的推导中已经体现了一种理论，即裴蜀定理用数学表示为：$存在x,y \in Z,使ax+by = m (a,b,m \in Z)的充要条件是m为\gcd(a,b)的倍数$。

其实这个扩展欧几里得算法模板不难，难在它的使用与理解。扩欧解决的是$ax+by = m$的问题。那么将问题转化一下，见题目[P1082同余方程](https://www.luogu.com.cn/problem/P1082)，一道非常经典的扩欧题目。

在题目中我们解决的是$ax \equiv 1 \pmod{p}$的最小正整数解，我们可以将式子改写为$ax + py = 1$，那么我们又回到扩欧了，求解$x$与$y$的值，这个时候其实我们不能保证$x$就是正整数，所以需要结合我们的通解式子，$x = x_0 - t \times \frac{b}{d},t$可正可负，只要非零即可那么我们再转化一下$x = x_0 + t \times \frac{b}{d}$，题目中已知 $d$为 $1$，因为题目中已知对于所有的样例都有对应的$x$值，而$\gcd(a,b) = 1$，那么$a$与$b$必定互斥。所以$x = x_0 + t \times b$，那么只需要将$x$变为`(x % b + b) % b`输出即可。所以我们的扩欧还可以解决这类的题目。
