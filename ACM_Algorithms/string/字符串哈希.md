#字符串哈希
# 定义
我们将一个字符串通过一个函数$f$实现对整数的唯一映射，且对于不同字符串来说，映射的哈希值唯一，那么$f$称为$Hash$函数，我们可以通过$f$实现判断两个字符串是否相等。

# 性质
具体来说，哈希函数最重要的性质可以概括为下面两条：

1. 在 Hash 函数值不一样的时候，两个字符串一定不一样；
2. 在 Hash 函数值一样的时候，两个字符串不一定一样（但有大概率一样，且我们当然希望它们总是一样的）。

我们将 Hash 函数值一样但原字符串不一样的现象称为哈希冲突。

# 实现
一般来说我们对于字符串的哈希使用的是多项式哈希。

$\text{Hash}(s) = \left( s[0] \cdot base^{n-1} + s[1] \cdot base^{n-2} + \cdots + s[n-1] \cdot base^0 \right) \mod m$

## 进制哈希
进制哈希的核心便是给出一个固定进制**base**，将一个串的每一个元素看做一个进制位上的数字，所以这个串就可以看做一个**base**进制的数，那么这个数就是这个串的哈希值；则我们通过比对每个串的的哈希值，即可判断两个串是否相同。

**代码：**

```cpp
unsigned long long Hash(string s){
    int len = s.length();
    unsigned long long num = 0;
    for (int i=0;i<len;++i){
        num = (num*BASE+(int)s[i])%MOD;
    }
    return num;
}
```

取模运算符会进一步增大性能开销，往往不推荐。但如果非要手动取模，那么为了保证哈希生成质量，**常量**`**mod**`**的值应取远大于**`**base**`**的质数**，例如：`131313`、`1610612741`等。

## 自然溢出哈希
c++中对于`unsigned long long`数据类型来说，当其超出数据范围时会自动对$ 2^{32}-1 $取模，也就有了对MOD取模的必要

代码：

```cpp
unsigned long long Hash(string s){
    int len = s.length();
    ull num = 0;
    for (int i=0;i<len;++i){
        num = (num*BASE+(int)s[i]);
    }
    return num;
}
```

## 字串哈希计算
$\text{Hash}(l, r) = \left( H[r+1] - H[l] \cdot P[r-l+1] \right) \mod m$

（需处理负数时：`(x % m + m) % m`）

其中$P$数组需要对字符串进行哈希前缀化处理：

$$
{\large
\begin{align*}
H[0] &= 0 \\
H[i] &= (H[i-1] \cdot base + s[i-1]) \mod m \\
P[0] &= 1 \\
P[i] &= (P[i-1] \cdot base) \mod m
\end{align*}
}
$$
