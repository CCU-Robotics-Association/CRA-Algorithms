#矩阵快速幂
快速幂其实已经算是简单算法了，代码如下：

```cpp
int qpow(int base,int power) {
    int res = 1;
    while(power){
        if (power & 1) res = res * base % MOD;
        base = base * base % MOD;
        power >>= 1;
    }
    return res;
}
```

而矩阵快速幂仅仅只是将我们的base换成了一个矩阵来进行幂运算。

观察我们的`qpow`方法，其实对于我们的快速幂的运算满足递推关系，本质上就是将power转化为二进制，我们的答案去乘上power二进制中为1的项

$3^{5} = 3^{4+1} = 3^4 \times 3^1 = 3^{100B} \times 3^{1B}$我们发现可以对次数项$5$进行二进制拆分，有效的仅仅只是$1$的部分。

这就是一种递推关系，我们每次对次数项进行二分，找到1就乘上对应次数项的值即可。

然后我们的矩阵快速幂呢也同样如此，只不过需要将$base$换成一个矩阵罢了。

我们以斐波那契数列为例，设斐波那契数列的递推公式为：$[F(n),F(n-1)] = [F(n-1),F(n-2)] \times base$
而我们已知斐波那契为$F(n) = F(n-1)+F(n-2)$
令$base$数组为$\begin{bmatrix}a & b\\c & d\end{bmatrix}$，带入公式为$\left\{\begin{matrix}a*F_{n-1} + c*F_{n-2} = F_{n}\\b*F_{n-1} + d*F_{n-2} = F_{n-1}\end{matrix}\right.$，
计算得到$base$数组为：$\begin{bmatrix} 1 & 1\\ 1 & 0\end{bmatrix}$
于是我们可以得到：$[F(n),F(n-1)] = [F(n-1),F(n-2)] \times \begin{bmatrix} 1 & 1\\ 1 & 0\end{bmatrix}$
我们将$F_1 = 1,F_2 = 1$带入得，$[F(n),F(n-1)] = [1,1]*\begin{bmatrix} 1 & 1\\ 1 & 0\end{bmatrix}^{n-2}$
那么我们就可以通过这个递推公式来先求出$\begin{bmatrix} 1 & 1\\ 1 & 0\end{bmatrix}^{n-2}$的值，然后再乘$[1,1]$即可

# 题目
熊猫正在玩一个游戏，他带着一支由$n$个角色组成的小队，角色编号从$1$到$n$。每一回合开始时，小队会拥有点能量（Ap）。

每个角色$i$都有一个技能，能造成$a_i$点伤害，通常消耗$c_i$点能量。每回合，每个角色可以选择使用一次技能，或者干脆不动，零消耗。所有技能的能量消耗总和不能超过$m$。回合结束时，剩余的能量会被清零，下一回合小队会重新获得$m$点能量。

游戏的特别机制是：如果角色在某回合使用了技能，那么下一回合该技能的能量消耗会变成$c_i+k$。如果角色连续多回合使用技能，消耗保持在$c_i+k$（不会继续增加）。如果某回合角色没用技能，那么下一回合的技能消耗会重置回$c_i$。

熊猫想在$R$个回合内，最大化造成的总伤害。请帮他算出能达到的最高伤害。

## 输入
第一行是一个整数$T(1 \le T \le 100)$，表示测试用例的数量。

每个测试用例的第一行包含四个整数$n,m,k,R(1 \le n \le 6,1 \le m,k \le 10^3,1 \le R \le 10^9)$。其中$n$是小队角色数，$m$是每回合开始获得的能量，$k$是技能使用后临时增加的能量消耗，$R$是总回合数。

接下来$n$行，每行两个整数$a_i,c_i(1 \le a_i \le 10^6,1 \le c_i \le m)$，分别是角色$i$的伤害值和初始能量消耗。

## 输出
输出一个整数，表示能达到的最大总伤害。

# 分析
由题目可知我们无法将这个大问题拆分成一个个小问题，所以考虑DP。

我们观察发现题目中所给的$n$很小。最大只有$6$，所以我们考虑对每个角色每个状态是否释放技能进行状态压缩，即以二进制的形式进行存储，当第$i$位为$1$时则释放技能，

为$0$则不释放技能，那么我们可以使用最大大小为$64$的数组来存储每个角色释放技能的情况。

定义$f_{i,t}$是到达第$i$回合，释放技能状态为$s$的时候能造成的伤害。当我们到达下一回合时势必会改变技能释放的情况，那么方程在进行转移的时候还需要对每个状态进行遍历，时间复杂度还要再乘上64，当我们$R$非常大时，时间复杂度比较高，那么我们考虑预处理从状态$t$到状态$s$的所有情况，那么只需要额外消耗$O(4^n)$的复杂度即可。

但是我们突然发现，比赛的回合数量高达$10^9$的大小，故再考虑矩阵快速幂。

我们先写出转移方程$f_{i,s} = max_{C_s+k\times popcount(s \& t) \le m}(f_{i-1,t}+A_s)$，我们每次从状态$s$到状态$t$都是这个转移方程，故可以用矩阵快速幂优化。我们定义$trans[s][t]$为从状态$s$到状态$t$所获得的伤害，对这个矩阵进行$R$次幂运算即可

# Code
```cpp
#include <bits/stdc++.h>
#define int long long
#define ull unsigned long long
using namespace std;
const int INF = 1e18+2;
const int N = 1e5+5;
const int MOD = 1e9+7;
struct Matrix{
    int a[65][65];
    int* operator[] (int k){return a[k];}
    Matrix():a(){};
    Matrix operator* (Matrix& b){
        Matrix res;
        for (int i=0;i<64;++i){
            for (int j=0;j<64;++j){
                res[i][j] = 0;
                for (int k=0;k<64;++k) res[i][j] = max(res[i][j],a[i][k]+b[k][j]);
            }
        }
        return res;
    }
};
void solve() {
    int n,m,k,R;
    cin>>n>>m>>k>>R;
    vector<int> a(n+1),c(n+1);
    for (int i=0;i<n;++i) cin>>a[i]>>c[i];
    vector<int> A(64);
    int S = (1LL << n);
    for (int i=0;i<S;++i){
        for (int j=0;j<n;++j){
            if (i & (1LL << j)) A[i] += a[j];
        }
    }
    Matrix trans;
    for (int i=0;i<S;++i){
        for (int j=0;j<S;++j){
            int cost = 0;
            for (int p=0;p<n;++p){
                if (j & (1LL << p)) cost += (i & (1LL << p)) ? c[p] + k : c[p];
            }
            if (cost > m) trans[i][j] = -INF;
            else trans[i][j] = A[j];
        }
    }
    function<Matrix(Matrix,int)> matrix_qpow = [&](Matrix base,int power)->Matrix{
        Matrix res;
        for (int i=0;i<64;++i){
            for (int j=0;j<64;++j) {
                res[i][j] = (i == j) ? 0 : -INF;
            }
        }
        while(power){
            if (power & 1) res = res * base;
            base = base * base;
            power >>= 1;
        }
        return res;
    };
    Matrix t = matrix_qpow(trans,R);
    int ans = 0;
    for (int i=0;i<64;++i) ans = max(ans,t[0][i]);
    cout<<ans<<'\n';
}
signed main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    // cout << fixed << setprecision(2);
    int t = 1;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```
