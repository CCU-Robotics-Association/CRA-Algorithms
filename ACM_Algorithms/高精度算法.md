#高精度
# 定义
高精度计算（Arbitrary-Precision Arithmetic），也被称作大整数（bignum）计算，运用了一些算法结构来支持更大整数间的运算（数字大小超过语言内建整型）。

# 存贮
平常实现中，高精度算法通常以字符串的形式输出，每一位表示一个进制位，所以高精度也是特殊的字符串处理。

读入字符串时，数字最高位在字符串首（下标小的位置）。但是习惯上，下标最小的位置存放的是数字的 最低位，即存储反转的字符串。这么做的原因在于，数字的长度可能发生变化，但我们希望同样权值位始终保持对齐（例如，希望所有的个位都在下标 `[0]`，所有的十位都在下标 `[1]`……）；同时，加、减、乘的运算一般都从个位开始进行（回想小学的竖式运算），这都给了「反转存储」以充分的理由。

所以不难写出高精度读入的代码：

```cpp
#include<bits/stdc++.h>
```

# 加减法
加减法对于高精度来说是比较简单的运算

## 加法
```cpp
vector<int> add(vector<int> a,vector<int> b){
    int len = max(a.size(),b.size())+1;
    vector<int> c(len,0);
    int i = 0;
    for (i=0;i<a.size() && i<b.size();++i){
        c[i] += a[i] + b[i];
        if (c[i]>=10){
            //若相加后其值大于10，需要进位，以下同理
            c[i]-=10;
            c[i+1]+=1;
        }
    }
    if (i<a.size()){
        for (;i<a.size();++i){
            c[i]+=a[i];
            if (c[i]>=10){
                c[i]-=10;
                c[i+1]+=1;
            }
        }
    }
    if (i<b.size()){
        for (;i<b.size();++i){
            c[i]+=b[i];
            if (c[i]>=10){
                c[i]-=10;
                c[i+1]+=1;
            }
        }
    }
    return c;
}
```
