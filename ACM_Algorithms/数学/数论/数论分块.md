
# 引入

数论分块可以快速计算一些形如
$$
\sum_{i=1}^ng\left(\left\lfloor\dfrac ni\right\rfloor\right)
$$

的和式，数论分块就可以在 $O(\sqrt{n})$ 时间内计算出上述和式的值。我们将其中的重点，也就是$\lfloor \frac{n}{i} \rfloor$提取出来，它是一个函数，形如$f(x) = \frac{n}{x}$，当$x$变化的时候，值也会变化。当$n$为$11$时，图像如下：

![](资源归档/assets/111.svg)

我们发现，当$x\le 3$时都是一个$x$对应一个$y$，当$x > 4$时就是多个$x$对应一个$y$值，我们把式子推广出去也就是说对应类似的式子$f(x) = \frac{n}{x}$，当$x\le \sqrt n$，都是一个$x$对应一个$y$，当$x > \sqrt n$时，就是多个$x$对应一个$y$，所以$\lfloor \frac{n}{i} \rfloor$不每次都变化，而是会在一个区间保持不变，于是我们就可以对这个区间进行分块处理，每次处理一个块而不是一个值，那么就可以把时间复杂度讲到$O(\sqrt n)$，为什么呢。

# 定义及其性质

我们令
$$
D(n) = \left\{\left\lfloor\dfrac{n}{i}\right\rfloor , 1 \le i \le n,~i\in\mathbf N_+\right\}
$$
其中$D(n)$这个集合就是我们分出来的块，那么
>[!note] 性质一
>$|D(n)|\le 2\sqrt{n}$．

>[!tip]- 证明
> - 当 $i\le\sqrt{n}$ 时，$i$ 的取值至多 $\sqrt{n}$ 个，所以 $\left\lfloor\dfrac{n}{i}\right\rfloor$ 的取值也至多只有 $\sqrt{n}$ 个。
> - 当 $i>\sqrt{n}$ 时，$\lfloor \frac{n}{i} = k \rfloor$，那么$\lfloor \frac{n}{k} = i \rfloor$，所以上一个取值存在 $\sqrt{n}$ 个，那么这一个也是。
> 
>因此，所有可能取值的总数 $|D(n)|\le 2\sqrt{n}$

>[!note] 性质二
>$|D(n)| = \lfloor \sqrt{4n+1}\rfloor - 1$。

>[!tip]- 证明
>太难了，未完待续

>[!note] 性质三
>对于 $d\in D(n)$，所有满足 $\left\lfloor\dfrac{n}{i}\right\rfloor=d$ 的整数 $i$ 的取值范围为$$\left\lfloor\dfrac{n}{d+1}\right\rfloor + 1\le i \le \left\lfloor\dfrac{n}{d}\right\rfloor$$

>[!tip]- 证明
>因为 $\left\lfloor\dfrac{n}{i}\right\rfloor=d$ 相当于不等式    $$d\le \dfrac{n}{i} < d+1$$
>
>这进一步等价于
>
>$$\dfrac{n}{d+1} < i\le \dfrac{n}{d}$$
>
>利用 $i\in\mathbf N_+$ 这一点，可以对该不等式取整，它就等价于
>
>$$\left\lfloor\dfrac{n}{d+1}\right\rfloor + 1 \le i\le \left\lfloor\dfrac{n}{d}\right\rfloor$$

这一性质还体现了图像的对称性：每个块的右端点（前文图中的绿点）的集合恰为 $D(n)$．这很容易理解，因为整个图像关于直线 $y=x$ 是对称的。

# 实现

那么我们该如何对数字进行分块呢，来道小题吧。
$T$ 组数据，每组一个整数 $n$．对于每组数据，输出 $\sum_{i=1}^n\left\lfloor\dfrac ni\right\rfloor$
直接对应我们所学习的数论分块的知识。
在计算的过程中我们需要维护一个`l`和`r`作为每一个块的区间，根据性质三的内容即可。

```cpp
#include <bits/stdc++.h>
#define int long long
#define ull unsigned long long
#define i128 __int128_t
using namespace std;
const int INF = 1e18;
const int N = 1e6 + 5;
const int MOD = 1e9 + 7;
void solve() {
	int n,ans = 0;
    cin>>n;
    // 维护的是i作为左端点，j作为右端点
    for (int i = 1,j;i <= n;i = j + 1) {
	    // d为n/i的值
        int d = n / i;
        // 右区间公式
        j = n / d;
        // 区间数量乘上区间的值
        ans += (j - i + 1) * (n / i);
    }
    cout<<ans<<'\n';
}
signed main() {
	ios::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);
	cout << fixed << setprecision(15);
	int t = 1;
	cin >> t;
	while (t--) {
		solve();
	}
	return 0;
}
```

# 向上取整的数论分块

在上述中讲到的都是$\lfloor\dfrac ni\rfloor$这种形式的，那倘若题目中要求我们求向上取整的形式呢，也就是$\lceil \frac{n}{i} \rceil$的形式。那我们只需要稍微转化一下式子。
由于$\lceil \frac{n}{i} \rceil = \lfloor \frac{n - 1}{i} \rfloor + 1$，那么我们的性质三转化为：
$$
\begin{align}
 &\lceil \frac{n}{i} \rceil = d \\
 &d - 1  < \frac{n}{i} \le d \\
 & 由于 i\in\mathbf N_+ \\
 &\lfloor \frac{n - 1}{d} \rfloor + 1 \le i \le \lfloor \frac{n-1}{d-1} \rfloor
\end{align}
$$

这时候对于 $d\in D(n)$，所有满足 $\left\lfloor\dfrac{n}{i}\right\rfloor=d$ 的整数 $i$ 的取值范围为$${\Large \lfloor \frac{n - 1}{d} \rfloor + 1 \le i \le \lfloor \frac{n-1}{d-1} \rfloor}$$
>[!warning]- 特别注意
>当$d$等于$1$的时候右边式子除$0$了，无意义。由于$\lceil \frac{n}{i} \rceil = 1$，于是我们可以直接写出$\lceil \frac{n}{i} \rceil = 1 \Leftrightarrow 0 < \frac{n}{i} \le 1 \Rightarrow i \ge n$，即$i$只需要大于等于$n$即可满足。

# 多维数论分块
数论分块有时包含不只有一个取整式的和式
$$
\sum_{i=1}^ng\left(\lfloor\frac{n_1}{i}\rfloor,\lfloor\frac{n_2}{i}\rfloor,\dots,\lfloor\frac{n_m}{i}\rfloor\right)
$$

为了应用数论分块的思想，需要保证每块中所有取整式 $\left\lfloor\dfrac {n_1}i\right\rfloor,\left\lfloor\dfrac {n_2}i\right\rfloor,\cdots,\left\lfloor\dfrac {n_m}i\right\rfloor$ 的取值都不发生变化，换句话说定义限制了我们分块需要满足：
- 对于某个分块的左端点 $l$ 和右端点 $r$ ，必须满足$$i \in [l,r],\lfloor\frac{n_1}{i}\rfloor,\lfloor\frac{n_2}{i}\rfloor,\dots,\lfloor\frac{n_m}{i}\rfloor的值保持不变$$

为此，对于已知的左端点 $l$，相应的右端点为
$$
\min\left\{\left\lfloor\dfrac {n_1}{\lfloor n_1/l\rfloor}\right\rfloor,\left\lfloor\dfrac {n_2}{\lfloor n_2/l\rfloor}\right\rfloor,\cdots,\left\lfloor\dfrac {n_m}{\lfloor n_m/l\rfloor}\right\rfloor\right\}.
$$

常见的为二维形式的。

# 任意指数的数论分块
数论分块可以用于含有任意指数的取整式的和式计算：
$$
\sum_{i=1}^{\lfloor n^{\alpha/\beta}\rfloor}g\left(\left\lfloor\dfrac {n^\alpha}{i^\beta}\right\rfloor\right).
$$
其中，$\alpha,\beta$ 为正实数．本文讨论的基本形式中，$\alpha=\beta=1$。
那么我们数论分块的定义为    
$$
D(n,\alpha,\beta) = \left\{\left\lfloor\dfrac{n^\alpha}{i^\beta}\right\rfloor: i=1,2,\cdots,\lfloor n^{\alpha/\beta}\rfloor\right\}.
$$
那么依旧有    
1. $|D(n,\alpha,\beta)|\le 2n^{\alpha/(1+\beta)}$．
2. 对于 $d\in D(n,\alpha,\beta)$，使得 $\left\lfloor\dfrac{n^\alpha}{i^\beta}\right\rfloor=d$ 成立的 $i$ 的取值范围为
$$
\left\lfloor\dfrac{n^{\alpha/\beta}}{(d+1)^{1/\beta}}\right\rfloor + 1\le i \le \left\lfloor\dfrac{n^{\alpha/\beta}}{d^{1/\beta}}\right\rfloor.
$$
>[!tip]- 证明
>- 当 $i\le \dfrac{n^\alpha}{i^\beta}$ 时，有 $i\le n^{\alpha/(1+\beta)}$，所以 $\left\lfloor\dfrac{n^\alpha}{i^\beta}\right\rfloor$ 至多有 $n^{\alpha/(1+\beta)}$ 种取值．
>- 当 $i > \dfrac{n^\alpha}{i^\beta}$ 时，跟之前的证明相同，不再赘述了。
>综合两种情形，就有 $|D(n,\alpha,\beta)|\le 2n^{\alpha/(1+\beta)}$．
>对于第二点，$\left\lfloor\dfrac{n^\alpha}{i^\beta}\right\rfloor=d$ 就等价于
>$$d \le \dfrac{n^\alpha}{i^\beta} < d+1 \iff \dfrac{n^{\alpha/\beta}}{(d+1)^{1/\beta}} < i \le \dfrac{n^{\alpha/\beta}}{d^{1/\beta}}\Rightarrow \lfloor \dfrac{n^{\alpha/\beta}}{(d+1)^{1/\beta}} \rfloor + 1 \le i \le \lfloor \dfrac{n^{\alpha/\beta}}{d^{1/\beta}} \rfloor$$



> [!example]- 例子
> 例如，对于 $\alpha=\beta=1/2$ 时的如下和式
> $$\sum_{i=1}^ng\left(\left\lfloor\sqrt{\dfrac {n}{i}}\right\rfloor\right)$$
> 可以通过数论分块在 $O(n^{1/3})$ 时间内解决．已知块的左端点为 $l$ 时，可以计算右端点为 $r=\left\lfloor\dfrac{n}{\lfloor\sqrt{n/l}\rfloor^2}\right\rfloor$
