# 动态规划
1.重叠子结构

将一个多阶段问题分成几个相互联系的单阶段问题，各个单阶段问题类型相同。先逐个解决每个单阶段，最后解决我们所需要的那个问题。简单来讲就是采用了“分治”的思想。一般来讲重叠子结构的算法也可以用递归解决。

2.最优子结构

利用前面已经解决的子问题最优解来构造并解决后面的子问题。能够构造的前提就是要满足指标函数的分离性，也就是全局最优解一定能够拆成子问题的最优解，从而递推解决。

对应到算法中，就是按照自底向上的策略，首先找到子问题的最优解，解决子问题，然后逐步向上找到问题的一个最优解。也就是说，整体问题的最优解包括了子问题的最优解。我们又叫做”最优子结构“。

（非常简单）例：斐波那契数列，输入一个数字代代表第几项，输出该项的值

```c
//动态规划实现斐波那契数列
#include<stdio.h>
int main(void)
{
   int arr[10]={1,1};
   for (int i=2;i<10;i++)
   {
      arr[i]=a[i-1]+arr[i+1];
   }

```

列出动态规划转移方程`f[i]=f[i-1]+f[i-2]`

利用arr数组存贮每一项的值，根据斐波那契数列的性质，输出相应的值。

（容易）例：![](资源归档/assets/107.png)



```c
#include<stdio.h>
int x1, y1, x2, y2;
const int c1[] = { 0,2,-2,1,-1,2,-2,1,-1 };
const int c2[] = { 0,-1,1,-2,2,1,-1,2,-2 };
long long arr[40][40];
int m[40][40];
int main(void) {
    scanf("%d %d %d %d", &x1, &y1, &x2, &y2);
    x1 += 2, y1 += 2, x2 += 2, y2 += 2;
    for (int _=0; _ < 9; _++) {
        m[x2 + c1[_]][y2 + c2[_]] = 1;
    }
    arr[2][2] = 1;
    for (int i = 2; i <= x1; i++) {
        for (int j = 2; j <= y1; j++) {
            if (m[i][j] == 1 || (i == 2 && j == 2)) {
                continue;
            }
            else {
                arr[i][j] = arr[i - 1][j] + arr[i][j - 1];
            }
        }
    }
    printf("%lld", arr[x1][y1]);
    return 0;
}
```



列出动态规划转移方程：`f[i][j]=f[i-1][j]+f[i][j-1]`

利用数组arr存贮每到某个格子所需要的步数，m数组则存储马以及被马所影响的位置（用数组`c1`、`c2`对`m`进行改变，将被马影响的部分设为$1$），根据题目要求遍历arr的每个值并用状态转移方程对每个坐标的步数进行修改，最后输出。

（中等）例：最大子序列和![](资源归档/assets/108.png)

```c
#include<stdio.h>
int main(void){
   int arr[]={-2,1,-3,4,-1,2-1,-5,4};
   int dp[1000];
   int len=sizeof(arr)/sizeof(arr[0]);
   int ans=0;
   dp[0]=arr[0];
   for (int i=1;i<len;i++){
      dp[i]=(dp[i-1]>0?dp[i-1]:0)+arr[i];
      ans=(dp[i]>ans?dp[i]:ans);
   }
   printf("%d",ans);
   return 0;
}
```

此题用动态规划的解法非常巧妙。动态规划的重点在于找出动态规划转移方程，找这个方程一定需要满足重叠子结构和最优子结构。倘若用平常的思维来思考，`f3=maxArray{-2,1,-3}`为$1$，但如果增加后一位$4$的话`f4=maxArray{-2,1,-3,4}`的值为$4$，并没有什么式子能将$f3$和$f4$相取得联系，所以得转换思路。我们发现，要解出这样的一个子序列，首先它们连续，所以当一遍遍历的过程中，倘若能筛选部分负数就可以实现找出最大子序列，运用动态规划的思想，首先`dp`数组存贮每个索引到达该`arr`位置时的最大子序列，如果我们在下一个索引进行和运算时能消去前部分子序列和为负数带来的影响，或许可以，在每次相加时运用三元运算符即可实现，然后加上该位置的值，规划方程就有了：`dp[i]=max(dp[i-1],0)+arr[i]`。巧妙之处在于每次序列和的起点可以由前子序列决定。

# 动态规划--01背包问题
问题取自：[2. 01背包问题 - AcWing题库](https://www.acwing.com/problem/content/2/)

有$N$件物品和一个容量是$V$的背包。每件物品只能使用一次。

第$i$件物品的体积是 $v_i$，价值是 $w_i$。

求解将哪些物品装入背包，可使这些物品的总体积不超过背包容量，且总价值最大。  
输出最大价值。

**输入格式**

第一行两个整数，$N$，$V$，用空格隔开，分别表示物品数量和背包容积。

接下来有$N$行，每行两个整数 $v_i$,$w_i$，用空格隔开，分别表示第 $i$ 件物品的体积和价值。

**输出格式**

输出一个整数，表示最大价值。

**数据范围**
$0<N,V\le 1000$
$0<v_i,w_i\le 1000$

```plain
4 5
1 2
2 4
3 4
4 5
```

```plain
8
```

0-1 背包即是不断对第 𝑖个物品的做出决策，「0-1」正好代表不选与选两种决定。

| 背包容量j   物品编号i |  0  |  1  |  2  |  3  |  4  |  5  |
|:---------------------:|:---:|:---:|:---:|:---:|:---:|:---:|
|           0           |  0  |  0  |  0  |  0  |  0  |  0  |
|           1           |  0  |  2  |  2  |  2  |  2  |  2  |
|           2           |  0  |  2  |  4  |  6  |  6  |  6  |
|           3           |  0  |  2  |  4  |  6  |  6  |  8  |
|           4           |  0  |  2  |  4  |  6  |  6  |  8  |

倘若我们遇到一个物品时就会遇到两种选择，把它_放进背包_和_不放进背包_，倘若放进背包那么对应背包容量就要减少该物品的体积同时要加上该物品的价值，在其中两个选择里面挑选其中的最优解，既价值最大的那一个。

我们用i表示遇到某物品，用j表示背包的总容量，那么我们不难写出背包问题的动态规划转移方程：

`f[i][j]=max(f[i-1][j],f[i][j-volume[i]]+value[i])`

其中i表示遇到某物品的编号，j表示背包总体积。

`f[i-1][j]`表示选择一：不买该物品后的总价值（即背包总容量不变的情况下遇到上一个物品时候背包的总价值）

`f[i-1][j-volume[i]]+value[i]`表示选择二：买了该物品后的总价值`[i-1]`（表示上一个物品）`[j-volume[i]]`（表示上一个物品时给这个物品预留体积时的背包容量）再加上对应的价值

两者取大，即是我们所求的最优背包价值。

```cpp
#include<iostream>
int dp[1005][1005];
using namespace std;
int main(void) {
    int n, v, i, j, volume[1005], value[1005];
    cin >> n >> v;
    for (i = 1; i <= n; i++) {
        cin >> volume[i] >> value[i];
    }
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= v; j++) {
            if (j - volume[i] >= 0)
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - volume[i]] + value[i]);
            else
                dp[i][j] = max(dp[i - 1][j], 0);
        }
    }
    cout << dp[n][v] << endl;
    return 0;
}
```

## 优化一
上述代码中用了表格，定义了一个二维dp的数组，但其实一维数组足以解决这个问题，这样可以减少代码的空间复杂度。优化思路：二维数组中的i表示遇到某物品，那么其实在每次第一轮for循环里就刷新`f[j]`的值

定义`f[j]`为第N件物品时，背包容量j下的最大价值

**注意：**此时第二轮循环里的j应该从后往前遍历，在二维情况下，状态`f[i][j]`是由上一轮`i - 1`的状态得来的，`f[i][j]`与`f[i - 1][j]`是独立的。而优化到一维后，如果我们还是正序，则有`f[较小体积]`更新到`f[较大体积]`，则有可能本应该用第`i-1`轮的状态却用的是第i轮的状态。

例如：一维状态第i轮对体积为 3的物品进行决策，则`f[7]`由`f[4]`更新而来，这里的`f[4]`正确应该是`f[i - 1][4]`，但从小到大枚举j这里的`f[4]`在第i轮计算却变成了`f[i][4]`。当逆序枚举背包容量j时，我们求`f[7]`同样由`f[4]`更新，但由于是逆序，这里的`f[4]`还没有在第i轮计算，所以此时实际计算的`f[4]`仍然是`f[i - 1][4]`。

代码如下：

```cpp
#include<iostream>
int dp[1005];
using namespace std;
int main(void) {
    int n, v, i, j, volume[1005], value[1005];
    cin >> n >> v;
    for (i = 1; i <= n; i++) {
        cin >> volume[i] >> value[i];
    }
    for (i = 1; i <= n; i++) {
        for (j = v; j >= 1; j--) {
            if (j - volume[i] >= 0)
                dp[j] = max(dp[j], dp[j - volume[i]] + value[i]);
            else
                dp[j] = max(dp[j], 0);
        }
    }
    cout << dp[v] << endl;
    return 0;
}
```

## 优化二
边输入边处理

```cpp
#include<iostream>
using namespace std;
int dp[1005];
int main() 
{
    int n, m;   
    cin >> n >> m;

    for(int i = 1; i <= n; i++) {
        int v, w;
        cin >> v >> w;      // 边输入边处理
        for(int j = m; j >= v; j--)
            dp[j] = max(dp[j], dp[j - v] + w);
    }
    cout << dp[m] << endl;
    return 0;
}
```

# 动态规划--完全背包
问题取自[3. 完全背包问题 - AcWing题库](https://www.acwing.com/problem/content/description/3/)

问题与01背包相似，但是不同之处在于完全背包中的物品可以使用无数次，而01背包只能使用一次。在物品可以使用无数次的基础上，我们就写出了初级代码

```cpp
#include<iostream>
using namespace std;
int dp[1005];
int main(){
	int a[1005][2];
	int n, v;
    cin >> n >> v;
	for (int i = 1; i <= n; i++) {
		cin >> a[i][0] >> a[i][1];
	}
	for (int i = 1; i <= n; i++) {
		for (int j = 1; j <= v; j++) {
			for (int k = 0; k * a[i][0] <= j; k++) {
				dp[j] = max(dp[j - k * a[i][0]] + k * a[i][1], dp[j]);
			}
		}
	}
	return 0;
}
```

用k代表该物品使用了几次，再建立一个循环对容量进行dp，这样的作法答案没有问题，但是使用了三层循环，时间复杂度会大大增加，于是需要优化。

想到如果在上一次dp完一个物品后再对其进行动态规划，自己对自己dp或许就可以缩减为两层循环。

```cpp
#include<iostream>
using namespace std;
int dp[1005];
int main() {
	int a[1005][2];
	int n, v;
	cin >> n >> v;
	for (int i = 1; i <= n; i++) {
		cin >> a[i][0] >> a[i][1];
	}
	for (int i = 1; i <= n; i++) {
		for (int j = a[i][0]; j <= v; j++) {
			dp[j] = max(j - a[i][0] >= 0 ? dp[j - a[i][0]] + a[i][1] : dp[j], dp[j]);
		}
	}
	cout << dp[v] << endl;
	return 0;
}

```
