# ZMP 零力矩点

## 1. 简介

ZMP，全称 **Zero Moment Point**，中文通常称为**零力矩点**。

它是双足机器人和类人机器人平衡分析中最经典的概念之一。

ZMP 可以用来判断机器人当前的整体动力学状态是否能够被地面支撑区域稳定承受。

常见应用包括：

- 双足机器人行走
- 人形机器人平衡
- 步态生成
- 质心轨迹规划
- 支撑区域分析
- 动态稳定性判断

---

## 2. 核心思想

机器人站在地面上时，地面会通过接触区域对机器人产生：

- 支撑力
- 摩擦力
- 接触力矩

ZMP 定义为地面支撑平面上的一个特殊点。

在该点处，由机器人惯性和重力等产生的水平力矩分量为零。

对于平足双足机器人，如果 ZMP 位于支撑多边形内部，通常意味着当前规划在理想刚性接触假设下满足一个重要的动态平衡条件。

---

## 3. LIPM 条件下的 ZMP

在线性倒立摆模型中，假设质心高度恒定为：

```math
z_c
```

水平方向质心位置为：

```math
x
```

质心水平加速度为：

```math
\ddot{x}
```

则 ZMP 为：

```math
p_x
=
x
-
\frac{z_c}{g}
\ddot{x}
```

二维情况下：

```math
p_y
=
y
-
\frac{z_c}{g}
\ddot{y}
```

因此：

```math
\mathbf{p}_{zmp}
=
\mathbf{p}_{com}
-
\frac{z_c}{g}
\mathbf{a}_{com}
```

---

## 4. 公式含义

公式：

```math
p_x
=
x
-
\frac{z_c}{g}
\ddot{x}
```

包含两个主要部分。

第一部分：

```math
x
```

代表质心当前位置。

第二部分：

```math
\frac{z_c}{g}
\ddot{x}
```

表示质心加速度对 ZMP 的影响。

因此机器人即使质心位置没有变化，只要存在明显加速度，ZMP 也可能发生较大移动。

---

## 5. 支撑多边形

Support Polygon，支撑多边形，是机器人所有有效地面接触点的凸包。

单脚站立时，支撑多边形通常近似为脚底区域。

双脚同时接触地面时，支撑多边形会覆盖两只脚共同形成的区域。

如果：

```math
\mathbf{p}_{zmp}
\in
\mathcal{S}
```

其中：

```math
\mathcal{S}
```

表示支撑多边形，则通常认为 ZMP 满足支撑区域约束。

---

## 6. 为什么 ZMP 不能简单等同于质心投影

静止情况下：

```math
\ddot{x}
=
0
```

因此：

```math
p_x=x
```

此时 ZMP 与质心水平投影重合。

但动态运动时：

```math
\ddot{x}
\neq0
```

则：

```math
p_x\neq x
```

这正是 ZMP 在动态步态规划中的重要性。
