在学习平衡二叉树前，我们需要了解另外一种树型结构叫做二叉搜索树。

# 二叉搜索树
二叉搜索树满足几个条件，分别为：

1. 非空左子树的所有键值小于其根结点的键值。
2. 非空右子树的所有键值大于其根结点的键值。
3. 左、右子树都是二叉搜索树。

![](资源归档/assets/56.gif)

上面这张图就是二叉搜索树，满足左边的值小于中间的值小于右边的值就可以。

那么当我们查找元素的时候跟二分一样，从中间开始，比中间小的往左，比中间大的往右。所以平均查找的时间复杂度为$O(\log{n})$，最坏情况为$O(n)$。

二叉搜索树的ADT是这么定义的：

```cpp
template <typename T>
struct BSTNode {
	T data; //节点数据
	BSTNode<T>* left; //节点左指针
	BSTNode<T>* right; //节点右指针
	int size; //以目前节点为根节点的树的大小
	int count; //节点的数量

	//节点构造函数
	BSTNode(const T& val) :data(val), left(nullptr), right(nullptr), size(1), count(1) {};
};
```

二叉查找树的插入操作会根据插入的值与当前节点进行比较，倘若插入的值小于当前节点，那么就进入当前节点的左子树，反之则进入右子树，然后再递归进行判断，实现插入操作。

查找操作同理，会从树根开始查找，由于二叉查找树的特性，大于根节点的值都在根节点的右子树，小于根节点的值都在根节点的左子树，所以会根据查找的值来判断是去左子树还是右子树平均时间复杂度为$O(\log{n})$。

二叉搜索树最复杂的方法是删除和插入，尤其是删除：

<span style="color:orange;">当我们需要删除一个节点的时候，但是那个节点又有左右子树怎么办。我们使用Hibbard删除法，根据二叉搜索树的性质，删除节点的左子树的值都小于右子树，那么我们的思路就是把我们能找到的右子树的最小的节点接替被删除的节点，将找到的最小节点（需要接替的节点）从右子树删除，替换我们需要删除的节点的数据，原本需要删除节点的左子树继续接在节点上就可以了。倘若左右子树都不存在或者只存在一个，那么直接返回存在那个子树的根节点或nullptr就可以了。</span>

自己写的ADT：

```cpp
#pragma once
#ifndef BST
#define BST

#include <stdexcept>

template <typename T>
struct BSTNode {
	T data; //节点数据
	BSTNode<T>* left; //节点左指针
	BSTNode<T>* right; //节点右指针
	int size; //以目前节点为根节点的树的大小
	int count; //节点的数量

	//节点构造函数
	BSTNode(const T& val) :data(val), left(nullptr), right(nullptr), size(1), count(1) {};
};


template <typename T>
class BSTTree {
private:
	//根节点
	BSTNode<T>* root;
	int getSize(BSTNode<T>* node) const {
		if (node == nullptr) return 0;
		return node->size;
	}
	void pushup(BSTNode<T>* node) {
		node->size = getSize(node->left) + getSize(node->right) + node->count;
	}
	BSTNode<T>* insertNode(BSTNode<T>* node, const T& val) {
		if (node == nullptr) {
			return new BSTNode<T>(val);
		}
		if (node->data > val) {
			node->left = insertNode(node->left, val);
			pushup(node);
		}
		else if (node->data < val) {
			node->right = insertNode(node->right, val);
			pushup(node);
		}
		else {
			node->count++;
			node->size++;
		}
		return node;
	}
	BSTNode<T>* deleteNode(BSTNode<T>* node, const T& val) {
		if (node == nullptr) return nullptr;
		if (node->data > val) {
			node->left = deleteNode(node->left, val);
			pushup(node);
		}
		else if (node->data < val) {
			node->right = deleteNode(node->right, val);
			pushup(node);
		}
		else {
			node->count--;
			if (node->count == 0) {
				if (node->left == nullptr) {
					BSTNode<T>* temp = node->right;
					delete node;
					return temp;
				}
				else if (node->right == nullptr) {
					BSTNode<T>* temp = node->left;
					delete node;
					return temp;
				}
				BSTNode<T>* temp = findMinNode(node->right);
				node->data = temp->data;
				node->count = temp->count;
				temp->count = 1;
				node->right = deleteNode(temp, node->data);
				pushup(node);
			}
			else {
				node->size--;
			}
		}
		return node;
	}
	BSTNode<T>* findMinNode(BSTNode<T>* node) const {
		BSTNode<T>* current = node;
		if (current == nullptr) throw std::runtime_error("This Tree is Empty!");
		while (current && current->left != nullptr) current = current->left;
		return current;
	}
	BSTNode<T>* findMaxNode(BSTNode<T>* node) const {
		BSTNode<T>* current = node;
		if (current == nullptr) throw std::runtime_error("This Tree is Empty!");
		while (current && current->right != nullptr) current = current->right;
		return current;
	}
	bool searchNode(BSTNode<T>* node, const T& val) const {
		if (node == nullptr) return false;
		if (node->data == val) return true;
		else if (node->data > val) return searchNode(node->left, val);
		else return searchNode(node->right, val);
	}
	void destroyTree(BSTNode<T>* node) {
		if (node != nullptr) {
			destroyTree(node->left);
			destroyTree(node->right);
			delete node;
		}
	}
	int getHeight(BSTNode<T>* node) const {
		if (node == nullptr) return 0;
		int leftHeight = getHeight(node->left), rightHeight = getHeight(node->right);
		return 1 + std::max(leftHeight, rightHeight);
	}
public:

	//构造函数
	BSTTree() :root(nullptr) {};
	//析构函数
	~BSTTree() {
		destroyTree(root);
		root = nullptr;
	}
	//插入
	void insert(const T& val) {
		root = insertNode(root, val);
	}
	//判断是否非空
	bool isEmpty() const {
		return root == nullptr;
	}
	//查找树中是否存在某元素
	bool search(const T& val) const {
		return searchNode(root, val);
	}
	//删除某元素
	void remove(const T& val) {
		if (isEmpty()) throw std::runtime_error("Tree is Empty!");
		root = deleteNode(root, val);
	}
	//返回最小值
	T findMin() const {
		if (isEmpty()) throw std::runtime_error("Tree is Empty!");
		BSTNode<T>* node = findMinNode(root);
		return node->data;
	}
	//返回最大值
	T findMax() const {
		if (isEmpty()) throw std::runtime_error("Tree is Empty!");
		BSTNode<T>* node = findMaxNode(root);
		return node->data;
	}
	//获取树的大小
	int size() const {
		return getSize(root);
	}
	//获取树的高度
	int height() const {
		return getHeight(root);
	}
};

#endif // !BST

```

# 平衡二叉树
那么我们平衡二叉树是通过什么方法来使查找树达到平衡的呢？

首先需要知道一个定义：**<font style="color:#DF2A3F;">平衡二叉树的任意节点左子树和右子树的之间的高度差不能大于1（左右子树高度差称为该节点的平衡因子）</font>**

因为这个的限制，我们的二叉查找树就不会退化为链表，当我们插入`{1,2,3,4,5,6}`时就会变成这样

![](资源归档/assets/58.png)

下图就不是平衡二叉树

![](资源归档/assets/59.png)

因为对于5节点来说，左子树的高度为0而右子树的高度为2，平衡因子为-2，所以不是平衡二叉树（称为平衡二叉树**<font style="color:#DF2A3F;">失衡</font>**），我们需要进行一些操作使它变成平衡二叉树。

这个操作就是平衡二叉树的核心，一共就两个操作：左旋、右旋。

需要旋转的有这么几种情况：

+ LL型：插入左孩子的左子树，右旋。
+ RR型：插入右孩子的右子树，左旋。
+ LR型：插入左孩子的右子树，先左旋再右旋。
+ RL型：插入右孩子的左子树，先右旋再左旋。

![](资源归档/assets/60.png)

## 右旋
右旋，顾名思义是二叉树往右边旋转

![](资源归档/assets/61.gif)

![](资源归档/assets/62.webp)

这种旋转适用于**<font style="color:#4861E0;">LL型</font>**，也就是<font style="color:#70000D;">左子树的高度大于右子树</font>

右旋操作就是将根节点下放到它左子节点的右边，然后根节点的左子节点成为新的根节点，满足根节点左子树的值小于根节点小于右子树。

那么有一个问题就是如果它右边有树怎么办？那就说明二叉树最先失衡的地方在下面，所以我们平衡二叉树一般都是从下往上递归，先处理下面失衡的树，再来上面的节点处理失衡问题。

因为如果失衡了那就说明肯定有一个节点它的左右子树的高度差大于1，所以所以必定有一个节点的右子树的空的，那个节点的父节点就是最先失衡的节点。

```cpp
AVLNode<T>* rightRotate(AVLNode<T>* node) {
        AVLNode<T>* x = node->left;
        AVLNode<T>* y = x->right;
        x->right = node;
        node->left = y;
        updateNode(node);
        updateNode(x);
        return x;
    }
```

ADT

```cpp
#pragma once
#ifndef AVL
#define AVL
#include <stdexcept>
template <typename T>
struct AVLNode {
	T data; //存储数据
	AVLNode<T>* left; //左子树
	AVLNode<T>* right; //右子树
	int count; //当前节点的个数
	int height; //以当前节点为根节点的树的高度
	int size; //以当前节点为根节点的树的大小

	AVLNode(const T& val) : data(val), left(nullptr), right(nullptr), count(1), height(1), size(1) {};
};

template <typename T>
class AVLTree {
private:
	//根节点
	AVLNode<T>* root;
	int getHeight(AVLNode<T>* node) const {
		return (node == nullptr ? 0 : node->height);
	}
	int getSize(AVLNode<T>* node) const {
		return (node == nullptr ? 0 : node->size);
	}
	void updateNode(AVLNode<T>* node) {
		if (node == nullptr) return;
		node->height = 1 + std::max(getHeight(node->left), getHeight(node->right));
		node->size = node->count + getSize(node->left) + getSize(node->right);
	}
	int getBalance(AVLNode<T>* node) {
		return (node == nullptr ? 0 : getHeight(node->left) - getHeight(node->right));
	}
	AVLNode<T>* rightRotate(AVLNode<T>* node) {
		AVLNode<T>* x = node->left;
		AVLNode<T>* y = x->right;
		x->right = node;
		node->left = y;
		updateNode(node);
		updateNode(x);
		return x;
	}
	AVLNode<T>* leftRotate(AVLNode<T>* node) {
		AVLNode<T>* x = node->right;
		AVLNode<T>* y = x->left;
		x->left = node;
		node->right = y;
		updateNode(node);
		updateNode(x);
		return x;
	}
	AVLNode<T>* insertNode(AVLNode<T>* node, const T& val) {
		if (node == nullptr) {
			return new AVLNode<T>(val);
		}
		if (val < node->data) {
			node->left = insertNode(node->left, val);
		}
		else if (val > node->data) {
			node->right = insertNode(node->right, val);
		}
		else {
			node->count++;
			updateNode(node);
			return node;
		}
		updateNode(node);
		int balance = getBalance(node);
		if (balance > 1 && val < node->left->data) {
			return rightRotate(node);
		}
		if (balance < -1 && val > node->right->data) {
			return leftRotate(node);
		}
		if (balance > 1 && val > node->left->data) {
			node->left = leftRotate(node->left);
			return rightRotate(node);
		}
		if (balance < -1 && val < node->right->data) {
			node->right = rightRotate(node->right);
			return leftRotate(node);
		}
		return node;
	}
	AVLNode<T>* findMinNode(AVLNode<T>* node) const {
		AVLNode<T>* current = node;
		while (current->left != nullptr) current = current->left;
		return current;
	}
	AVLNode<T>* findMaxNode(AVLNode<T>* node) const {
		AVLNode<T>* current = node;
		while (current->right != nullptr) current = current->right;
		return current;
	}
	bool searchNode(AVLNode<T>* node, const T& val) const {
		if (node == nullptr) return false;
		if (val < node->data) return searchNode(node->left, val);
		else if (val > node->data) return searchNode(node->right, val);
		else return true;
	}
	void destroyTree(AVLNode<T>* node) {
		if (node != nullptr) {
			destroyTree(node->left);
			destroyTree(node->right);
			delete node;
		}
	}
	AVLNode<T>* deleteNode(AVLNode<T>* node, const T& val) {
		if (node == nullptr) return nullptr;
		if (val < node->data) {
			node->left = deleteNode(node->left, val);
		}
		else if (val > node->data) {
			node->right = deleteNode(node->right, val);
		}
		else {
			node->count--;
			if (node->count == 0) {
				if (node->left == nullptr) {
					AVLNode<T>* temp = node->right;
					delete node;
					return temp;
				}
				else if (node->right == nullptr) {
					AVLNode<T>* temp = node->left;
					delete node;
					return temp;
				}
				else {
					AVLNode<T>* temp = findMinNode(node->right);
					node->data = temp->data;
					node->count = temp->count;
					temp->count = 1;
					node->right = deleteNode(node->right, temp->data);
				}
			}
			else {
				updateNode(node);
				return node;
			}
		}
		if (node == nullptr) return nullptr;
		updateNode(node);
		int balance = getBalance(node);
		if (balance > 1 && val < node->left->data) {
			return rightRotate(node);
		}
		if (balance < -1 && val > node->right->data) {
			return leftRotate(node);
		}
		if (balance > 1 && val > node->left->data) {
			node->left = leftRotate(node->left);
			return rightRotate(node);
		}
		if (balance < -1 && val < node->right->data) {
			node->right = rightRotate(node->right);
			return leftRotate(node);
		}
		return node;
	}
public:
	//构造函数
	AVLTree() :root(nullptr) {};
	//析构函数
	~AVLTree() {
		destroyTree(root);
		root = nullptr;
	}
	//插入
	void insert(const T& val) {
		root = insertNode(root, val);
	}
	//删除
	void remove(const T& val) {
		root = deleteNode(root, val);
	}
	//查找树中是否存在某元素
	bool search(const T& val) const {
		return searchNode(root, val);
	}
	//判断树是否非空
	bool isEmpty() const {
		return root == nullptr;
	}
	//返回树的最小值
	T findMin() const {
		if (isEmpty()) throw std::runtime_error("The Tree is Empty!");
		return findMinNode(root)->data;
	}
	//返回树的最大值
	T findMax() const {
		if (isEmpty()) throw std::runtime_error("The Tree is Empty!");
		return findMaxNode(root)->data;
	}
	//返回树的大小
	int size() const {
		return getSize(root);
	}
	//返回树的高度
	int height() const {
		return getHeight(root);
	}
};
#endif // !AVL

```

# 红黑树
前排提醒：红黑树相比于AVL树还要复杂，而且个人感觉复杂的不是一星半点。

红黑树，顾名思义是树的节点有红和黑两种颜色的树，红黑树不是**<font style="color:#DF2A3F;">高度平衡</font>**的，什么意思呢？就是它不像AVL树一样通过高度差来保持平衡，而是通过自身红黑的规则来保持一种特殊的内部平衡，它的规则如下：

+ 性质1：节点非<font style="color:#FFFFFF;">黑</font>即<font style="color:#DF2A3F;">红</font>
+ 性质2：根节点一定是黑色
+ 性质3：叶子节点（NIL）一定是黑色
+ 性质4：每个红色节点的两个子节点，都为黑色。(从每个叶子到根的所有路径上不能有两个连续的红色节点)
+ 性质5：从任一节点到其每个叶子的所有路径，都包含相同数目的黑色节点。

其中提到了一个特殊的节点名字为NIL，红黑树中所有的叶子节点下面还有一个空的黑色节点NIL，如下图。

![](资源归档/assets/69.png)

红黑树中只有NIL节点才是真正的叶子节点，而其他带数据的节点非黑即红。

我们再着重说明几个性质：

+ 根节点和叶子节点（NIL节点）必须是**黑色**。（定义）如上图
+ 红色节点不能两两相连，其他的随意
+ 性质5是维持红黑树平衡最关键的性质，从任意节点到其任意叶子节点（NIL）之间经过的黑色节点数量相同。可以看看上图数一数，看看是不是满足性质
+ ![](资源归档/assets/70.png)

那么其实按照这样的思路我们就可以写出节点的结构体了

+ 变色
+ 左右旋

接下来来红黑树的操作，最主要，最难的就是插入和删除

## 插入
我们插入节点的时候默认将插入的节点设置为红色。（因为效率比较高）

由于红黑树有parent指针域的存在所以我们不能使用递归来实现插入了。

插入分五种情况一个个来。

### CASE1
当我们红黑树为空的时候插入的节点直接从红色变成黑色即可

### CASE2
当我们插入节点的父节点为黑色的时候，由于插入的节点是红色的所以不用做任何操作。

### CASE3
当我们插入节点的父节点为红色并且叔叔节点也为红色的时候，如下图

![](资源归档/assets/71.png)

我们插入的节点由于默认为红色，而父节点和叔节点也为红色，倘若我们仅仅只是将插入节点和父节点的颜色改变了，那么此时的树不满足性质5，叔叔节点那棵树少了一个黑色节点

![](资源归档/assets/72.png)

注意不要忘了NIL节点也就是叶子节点。这时不平衡，所以最正确的做法应该是将父节点和叔节点一起变成黑色，并且祖父节点变成红色否则根节点的左右子树的黑色节点数量不同了。所以应该这么做。

![](资源归档/assets/73.png)

这时，由于我们的祖父节点变成了红色，而祖父的父节点颜色未知，所以我们递归回到祖父节点的父节点时还需要判断是否平衡并调整。

部分代码如下：

```cpp
RBNode<T>* uncle = grandparent->_right;
if (uncle && uncle->color == Red) {
	parent->color = uncle->color = Black;
	grandparent->color = Red;
	cur = parent;
	parent = cur->_parent;
}
```

如果父节点的在祖父节点的左侧那么插入的节点也需要在父节点的左侧，如果父节点的在祖父节点的右侧那么插入的节点也需要在父节点的右侧

根据对应需要进行左右旋，然后变色。第一次旋转是对父节点进行旋转将相反的方向回正，然后再对祖父节点进行旋转，回正这一部分红黑树。

### 插入的代码如下：
```cpp
void insertNode(const T& val) {
	if (root == nullptr) {
		root = new RBNode<T>(val);
		root->color = Black;
		return;
	}
	RBNode<T>* parent = nullptr;
	RBNode<T>* cur = root;
	while (cur) {
		if (cur->data > val) {
			parent = cur;
			cur = cur->_left;
		}
		else if (cur->data < val) {
			parent = cur;
			cur = cur->_right;
		}
		else {
			return;
		}
	}
	cur = new RBNode<T>(val);
	if (parent->data > val) parent->_left = cur;
	else parent->_right = cur;
	cur->_parent = parent;
	while (parent && parent->color == Red) {
		RBNode<T>* grandparent = parent->_parent;
		if (grandparent->_left == parent) {
			RBNode<T>* uncle = grandparent->_right;
			if (uncle && uncle->color == Red) {
				parent->color = uncle->color = Black;
				grandparent->color = Red;
				cur = parent;
				parent = cur->_parent;
			}
			else {
				if (cur == parent->_left) {
					rightRotate(grandparent);
					grandparent->color = Red;
					parent->color = Black;
				}
				else {
					leftRotate(parent);
					rightRotate(grandparent);
					grandparent->color = Red;
					cur->color = Black;
				}
				break;
			}
		}
		else {
			RBNode<T>* uncle = grandparent->_left;
			if (uncle && uncle->color == Red) {
				parent->color = uncle->color = Black;
				grandparent->color = Red;
				cur = parent;
				parent = cur->_parent;
			}
			else {
				if (cur == parent->_right) {
					leftRotate(grandparent);
					grandparent->color = Red;
					parent->color = Black;
				}
				else {
					rightRotate(parent);
					leftRotate(grandparent);
					cur->color = Black;
					grandparent->color = Red;
				}
				break;
			}
		}
	}
	root->color = Black;
}
```
