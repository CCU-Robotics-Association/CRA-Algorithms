# 笛卡尔树的构造
一般我们笛卡尔树的构造通常通过单调栈来辅助构造，我们以大顶堆为例，根据笛卡尔树的性质，笛卡尔树内节点的左子节点一定小于该节点并且在该节点的左边，所以我们找到单调栈中第一个小于该节点值的元素即为左边，而单调栈中第一个大于该节点的节点的右子节点就是它。

```cpp
int n,top = 0;
cin>>n;
vector<int> a(n + 1),st(n + 1),left(n + 1),right(n + 1);
for (int i=1;i<=n;++i) cin>>a[i];
for (int i=1;i<=n;++i) {
    int k = top;
    while(k && a[st[k]] < a[i]) --k;
    if (k) right[st[k]] = i;
    if (k < top) left[i] = st[k + 1];
    st[++k] = i;
    top = k;
}
```
