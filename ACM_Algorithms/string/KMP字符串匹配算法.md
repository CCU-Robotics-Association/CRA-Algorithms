# 朴素的模式匹配算法
主串与副串的指针一个个比较，当比较到不相同时主串指针回溯到上次与副串头指针相比较的位置，再逐步向下搜索比对。

```cpp
#include<iostream> //朴素字符串匹配方法
#include<algorithm>
using namespace std;
int match_string(string s1, string s2) {
    int i = 0, j = 0;
    while (i < s1.size() && j < s2.size()) {
        if (s1[i] == s2[j]) {
            i++, j++;
        }
        else {
            i = i - j + 1;
            j = 0;
        }
    }
    if (j == s2.size()) {
        return i - j;
    }
    else {
        return -1;
    }
}
int main() {
    string s1, s2;
    int p;
    cin >> s1 >> s2;
    p = match_string(s1, s2);
    if (p != -1) {
        cout << p << endl;
    }
    else {
        cout << "没有" << endl;
    }
    return 0;
}
```

假设我们的主串S=“goodgoogle”，子串T=“google”

(1) 从主串S的第一位开始，S与T的前三位都匹配成功，第四位匹配失败，此时将主串的指针退回到第二位，子串的指针退回子串开始，即从`S[1]`开始重新匹配。

![](资源归档/assets/48.png)

(2) 主串S从第二位开始于子串T匹配，第一步就匹配失败，将主串指针指向第三位`S[2]`，子串指针指向开头，继续匹配。

![](资源归档/assets/49.png)

(3) 同步骤二，第一步就匹配失败，将主串指针移动到第四位`S[3]`，子串指针指向开头，继续匹配。

![](资源归档/assets/50.png)

(4) 还是第一步就匹配失败，将主串指针移动到第五位`S[4]`，子串指针指向开头，继续匹配。

![](资源归档/assets/51.png)

(5) 到步骤5终于第一步能够匹配上，从`S[4]`开始指针依次向后移动，六个字母全部匹配上，匹配成功！

![](资源归档/assets/52.png)

该算法的时间复杂度为$O(n\times m)$，时间浪费较大。当最坏的情况时主串为S=“00000000000000000000000000000000000000000000000001”，子串为T=“0000000001”，推导一下可得此时的时间复杂度度为$O((n-m+1)\times m)$(n为主串长度)。

这种方法过于低效，因此才会产生KMP字符串匹配算法

# KMP字符串匹配算法
我们观察上面的匹配步骤发现，当匹配到不同字符串时主串指针回溯，副串指针也回溯，

![](资源归档/assets/43.png)

我们可以发现，在2、3、4步骤中，主串的首字符与子串的首字符均不等。我们仔细观察可以发现，对于子串"google"来说，首字母"g"与后面的两个字母是不相等的，而在步骤1中主串与子串的前三个字符相等，这就意味着子串的首字符"g"不可能与主串的二、三位相等，故上图中步骤2、3完全是多余的。

也就是说，如果我们知道子串的首字符"g"与后面两个字符不相等(此处需要进行一些预处理，这是后面的重点)，我们就不需要再进行2、3步操作，只保留1、4、5步即可。

![](资源归档/assets/44.png)

kmp则实现主串指针不回溯，副串指针回溯到与前面相应的位置。

在实现这个回溯的操作前我们先了解一下**前缀表**这个概念。前缀表是一张表(或者直接理解为一个数组)，表中记录的是字符串中的每个子串的最大相等前后缀的长度，这个概念有点长也有点抽象，举一个例子来具体说明一下。

设字符串T=“aabaaf”，我们求一下T的前缀表(用一个数组名为next的数组表示)。

1. 第一个子串是t0=“a”，易知该子串没有前缀也没有后缀，故`next[0]=0`
2. 第二个子串是t1=“aa”，该子串的前缀为"a"，后缀也为"a"，故`next[1]=1`
3. 第三个子串是t2=“aab”，该子串的后缀中一定会有"b"，前缀中一定不含有"b"，则其没有相等的前后缀，故`next[2]=0`
4. 第四个子串是t3=“aaba”，该子串的最大相等前后缀为"a"，长度为1，故`next[3]=1`
5. 第五个子串是t4=“aabaa”，该子串的最大相等前后缀为"aa"，长度为2，故`next[4]=2`
6. 第六个子串是t5=“aabaaf”，该子串的后缀中一定会有"f"，前缀中一定不含有"f"，则其没有相等的前后缀，故`next[5]=0`

我们就可以得到前缀表

| **j** | **0** | **1** | **2** | **3** | **4** | **5** |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| T | a | a | b | a | a | f |
| next | 0 | 1 | 0 | 1 | 2 | 0 |


其实前缀表决定了**子串指针j在匹配失败时回溯到的位置**。结论：**前缀表是用来回退的，它记录了模式串与主串(文本串)不匹配的时候，模式串应该从哪里开始重新匹配**。

假设主串S=“aabaabaaf”,子串T=“aabaaf”，我们已经求出了子串T的前缀表，采用KMP算法匹配的流程如下：

![](资源归档/assets/47.png)

从上面的流程可以看到，在子串的某一个字符`t[j]`处匹配失败时，我们需要查找该字符前面的那个子串的最大相等前后缀的长度，即`next[j-1]`，然后使j指针退回到`next[j-1]`，i指针不变，继续匹配，不断重复这个操作知道匹配成功或者j指针大于等于子串长度。在这里j指针之所以退回到`next[j-1]`的位置我们可以根据例子思考一下，字符"f"前面的子串为"aabaa"，该子串的最大相等前后缀为"aa"，而**该子串的后缀"aa"已经与`s[3]s[4]`比较过是相等的，那么子串的前缀就一定是与`s[3]s[4]`相等的**，不需要比较，因此我们的j可以从前缀的后面第一个字符开始匹配，而前缀的长度为`next[j-1]`，所以j应该回退到`next[j-1]`。

**而前缀表的实现就是字符串的自匹配**

那么**KMP**的实现只要两步：

**一、计算前缀表。**

**二、根据前缀表移动两个指针进行匹配。**

```cpp
#include<iostream> //kmp匹配方法
#include<cstring>
using namespace std;
void match_self(string s, int next[]) {//计算前缀表
	int j = 0;
	for (int i = 1; i < s.size(); i++) {
		while (j > 0 && s[j] != s[i]) j = next[j - 1];
		if (s[i] == s[j]) j++;
		next[i] = j;
	}
}
int kmp_string(string s1, string s2) {//字符串匹配
	int i = 0, j = 0;
	int next[100];
	next[0] = 0;
	match_self(s2, next);
	while (i < s1.size() && j < s2.size()) {
		while (j > 0 && s1[i] != s2[j]) j = next[j - 1];
		if (s1[i] == s2[j]) j++;
		if (j == s2.size()) return i - j + 1;
		i++;
	}
	return -1;
}
int main() {
	string s1, s2;
	int l;
	cin >> s1 >> s2;
	l = kmp_string(s1, s2);
	if (l != -1) {
		cout << l << endl;
	}
	else {
		cout << "无" << endl;
	}
	return 0;
}
```
