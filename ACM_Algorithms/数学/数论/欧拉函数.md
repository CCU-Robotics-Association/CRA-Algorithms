欧拉函数，即$\varphi (n)$ 。表示的是小于等于$n$的数字中与$n$互质的个数。
例如：$\varphi (1) = 1,\varphi (2) = 1,\varphi (3) = 2,\varphi (4) = 2,\varphi (5) = 4,\dots$ 。
当$n$为质数时，$\varphi (n) = n - 1$。

# 欧拉函数的性质

欧拉函数存在如下性质：
1. 欧拉函数为[[数论基础#积性函数 | 积性函数]]。即对任意满足 $\gcd(a, b) = 1$ 的整数 $a,b$，有 $\varphi(ab) = \varphi(a)\varphi(b)$．特别地，当 $n$ 是奇数时 $\varphi(2n) = \varphi(n)$。
> [!tip]- 证明
> 难度稍高，未完待续
2. $n = \sum_{d \mid n}{\varphi(d)}$．
3. 若 $n = p^k$，其中 $p$ 是质数，那么 $\varphi(n) = p^k - p^{k - 1}=(p-1)p^{k-1}$。
> [!tip]- 证明
> 我们要算$1 ~ p^k$中不能被$p$整除的数字的数量，直接算有些麻烦，我们反过来算，能被$p$整除的个数有多少，就是$p$的倍数，即$p,2p,3p,\dots,mp$其中$mp\le p^k$，两边同时除以$p$得到$1,2,3,\dots,m \le p^{k - 1}$，也就是说我们$m$可以取到$1,2,3,\dots,p^{k-1}$，一共$p^{k-1}$个，所以只需要将数字总个数$p^k$减去能被$p$整除的个数$p^{k-1}$即可。

# 求解欧拉函数
## 朴素求一个数字的欧拉函数值

我们已经了解到欧拉函数为积性函数，也就是说对于我们任意的整数值$n$，我们可以先[[分解质因数]]。得到$n = p_1^{\alpha_1} \times p_2^{\alpha_2} \times p_3^{\alpha_3} \times \dots \times p_k^{\alpha_k}$，而根据性质1、3我们可以写出如下式子：
$$
{\Large
\begin{align}
\varphi(n) =& \varphi(p_1^{\alpha_1} \times p_2^{\alpha_2} \times p_3^{\alpha_3} \times \dots \times p_k^{\alpha_k}) \\
=& \prod_{i = 1}^{k}\varphi(p_i^{\alpha_i})  &性质1\\
=& \prod_{i=1}^{k} p_i^{k-1}(p_i-1) &性质3\\
=& \prod_{i=1}^{k} p_i^k(1-\frac{1}{p_i}) \\
=& n \prod_{i=1}^{k} (1-\frac{1}{p_i}) \\
=& n \prod_{i=1}^{k} \frac{p_i - 1}{p_i} \\
\end{align}
}
$$
代码如下：
```cpp
int n,ans;
cin>>n;
ans = n;
for (int i=2;i * i <= n;++i) {
    if (n % i == 0) {
        ans = ans / i * (i - 1);
        while(n % i == 0) n /= i;
    }
}
if (n != 1) ans = ans / n * (n - 1);
cout<<ans<<'\n';
```
时间复杂度为$O(\sqrt n)$。
## 欧拉筛求解欧拉函数
当我们需要求解$[1,n]$范围内所有数的欧拉函数，一个个计算时间复杂度过高，所以需要欧拉筛来辅助。（欧拉筛见[[素数筛法#欧拉筛（线性筛）| 欧拉筛]]）
我们已知欧拉筛在筛的过程中：
- 如果该数为质数，$\varphi(i) = i - 1$。
- 如果该数为合数，每个合数都会被它最小的质因数筛掉。设$p_j$为$x$的最小质因子，那么$x$就是被$p_j \times i$筛掉的，也就是$x = p_j \times i$。
	- 如果$p_j$是$i$的因数，那么$i$中已经包含了所有$x$的质因子。那么$${\Large
\begin{align}
\varphi(n) =& n \prod_{i=1}^{k} \frac{p_i - 1}{p_i} \\
=& p_j \times i \times \prod_{i=1}^{k} \frac{p_i - 1}{p_i} \\
=& p_j \times \varphi(i)
\end{align}
}$$
> [!tip]- 证明
> 我们$x$可以转化为$p_1^{\alpha_1} \times p_2^{\alpha_2} \times p_3^{\alpha_3} \times \dots \times p_k^{\alpha_k}$，由于$p_j$为$x$的最小质因子也就是式子中的$p_1$，而我们$x = p_j \times i = p_1 \times i$并且$i \% p_j = 0$所以$i = p_1^{\alpha_1 - 1} \times p_2^{\alpha_2} \times p_3^{\alpha_3} \times \dots \times p_k^{\alpha_k}$，即包含了所有$x$的质因子。


	- 如果$p_j$与$i$互质，那么就简单了$\varphi(x)=\varphi(p_j\times i)=\varphi(p_j) \times \varphi(i)=(p_j - 1) \times \varphi(i)$。

```cpp
int n,ans = 0;
cin>>n;
vector<int> oula(n + 1),fac;
vector<bool> flag(n + 1);
oula[1] = 1;
for (int i=2;i<=n;++i) {
    if (!flag[i]) {
        fac.push_back(i);
        oula[i] = i - 1;
    }
    for (const int& j : fac) {
        int x = i * j;
        if (x > n) break;
        flag[x] = true;
        if (i % j == 0) { // p_j 与 i 为合数
            oula[x] = j * oula[i];
            break;
        }else oula[x] = (j - 1) * oula[i]; // p_j 与 i 互质
    }
}
```

时间复杂度为$O(n)$。

# 例题

## P2155 [SDOI2008] 沙拉公主的困惑

### 题目描述

大富翁国因为通货膨胀，以及假钞泛滥，政府决定推出一项新的政策：现有钞票编号范围为 $1$ 到 $N$ 的阶乘，但是，政府只发行编号与 $M!$ 互质的钞票。房地产第一大户沙拉公主决定预测一下大富翁国现在所有真钞票的数量。现在，请你帮助沙拉公主解决这个问题，由于数量可能非常大，你只需计算出答案对 $R$ 取模后的结果即可。

### 输入格式

第一行为两个整数 $T$ 和 $R$，其中 $T$ 为该组中测试数据数目，$R$ 为模数。

接下来 $T$ 行，每行一对整数 $N$ 和 $M$，具体意义见题目描述。

### 输出格式

共 $T$ 行，对于每一对 $N$ 和 $M$，输出 $[1, N!]$ 中与 $M!$ 互质的数的数量对 $R$ 取模后的值。

### 输入输出样例 #1

#### 输入 #1

```
1 11
4 2
```

#### 输出 #1

```
1

```

### 说明/提示
对于 $100\%$ 的数据，$1\leq M\leq N\leq 10^7$，$1\leq T\leq 10^4$，$2\leq R\leq 10^9+10$ 且 $R$ 为质数。

### 思路
在看到这道题的时候，说实话我是懵逼的，没有任何思路。看了题解才明白自己的问题。
首先，我们需要知道一个前置知识，就是在求`gcd`的时候用到的欧几里得算法，其中有一条性质$$\gcd(a,b) = \gcd(a + k\times b,b)$$
在这里就不证明了。知道了这个之后由于题目中说的$M\le N$，所以$M! | N!$，我们将上面的式子中的$b$换成$M!$，得到$\gcd(x+k\times M!,M!)$，可以发现：对于$\forall k \in [1,\frac{N!}{M!}],\forall x\in [1,M!]$存在$\gcd(x + k\times M!,M!) = \gcd(x,M!)$，也就是说$${\Large
\begin{align}
ans =& \sum_{i=1}^{N!}[\gcd(i,M!)==1] \\
=& \sum_{k=1}^{\frac{N!}{M!}} \sum_{x=1}^{M!} \gcd((k-1)\times M! + x,M!)
\end{align}
}$$
而其中，无论$k$取什么值，由于上面的性质，我们可以知道$\forall k \in [1,\frac{N!}{M!}]$每个$k$得到的值是相同的，都是$\varphi(M!)$在$[(k-1)\times M!+1,M!]$这个区间内。而这不同的$k$可以取$\frac{N!}{M!}$次。于是就得到了解题的关键式子：$$ans = \frac{N!}{M!} \times \varphi(M!)$$
于是，我们的问题回到了该如何去求$\varphi(M!)$的问题上。
- 若$M$为质数，那么$$\begin{align}
\varphi(M!) =& M!\times \prod_{i=0}^{k} \frac{p_i-1}{p_i} &因为M和M!的质因子相同\\
=& M \times \frac{M-1}{M} \times(M-1)! \times \prod_{i=0}^{k-1} \frac{p_i-1}{p_i} &我把最后一个质数，也就是M提出来了 \\
=& (M-1) \times \varphi((M-1)!)
\end{align}$$
- 若$M$为非质数，那么$$\begin{align}
\varphi(M!) =& M!\times \prod_{i=0}^{k} \frac{p_i-1}{p_i} \\
=& M\times (M-1)! \times \prod_{i=0}^{k} \frac{p_i-1}{p_i} \\
=& M \times \varphi((M-1)!) &因为M和M-1的质因子相同
\end{align}$$
至此所有递推关系得到，我们就可以预处理所有的欧拉函数、阶乘以及阶乘的逆元即可。

```cpp
#include <bits/stdc++.h>
// #define int long long
#define ull unsigned long long
#define i128 __int128_t
using namespace std;
const int INF = 1e18;
const int N = 1e7 + 3;
int MOD = 1e9 + 7;
int fac[N],invfac[N],oula[N];
vector<int> prim;
bool is_prim[N];
int qpow(int base,int power) {
    int res = 1;
    while(power) {
        if (power & 1) res = 1LL * res * base % MOD;
        base = 1LL * base * base % MOD;
        power >>= 1;
    }
    return res;
}
void init() {
    fac[0] = fac[1] = 1;
    for (int i=2;i<N;++i) {
        if (i % MOD) fac[i] = 1LL * fac[i - 1] * i % MOD;
        else fac[i] = fac[i-1];
    }
    invfac[N - 3] = qpow(fac[N - 3],MOD-2);
    for (int i=N-4;i>=1;--i) {
        int x = i + 1;
        if (x % MOD == 0) x = 1;
        invfac[i] = 1LL * invfac[i + 1] * x % MOD;
    }
    is_prim[0] = is_prim[1] = true;
    for (int i=2;i<N;++i) {
        if (!is_prim[i]) prim.push_back(i);
        for (const int& j : prim) {
            long long x = i * j;
            if (x >= N) break;
            is_prim[x] = true;
            if (i % j == 0) break;
        }
    }
    oula[0] = oula[1] = 1;
    for (int i=2;i<N;++i) {
        if (!is_prim[i]) oula[i] = 1LL * (i - 1) * oula[i - 1] % MOD;
        else oula[i] = 1LL * i * oula[i - 1] % MOD;
    }
}
void solve() {
    int n,m;
    cin>>n>>m;
    if ((m < MOD && n >= MOD) || n >= 2 * MOD) cout<<0<<'\n';
    else cout<<1LL * fac[n] * invfac[m] % MOD * oula[m] % MOD<<'\n';
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    cout << fixed << setprecision(15);
    int t = 1;
    cin >> t >> MOD;
    init();
    while (t--) {
        solve();
    }
    return 0;
}
```
