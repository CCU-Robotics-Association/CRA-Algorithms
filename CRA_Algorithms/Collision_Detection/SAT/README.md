# SAT 分离轴定理碰撞检测

## 1. 简介

SAT（**Separating Axis Theorem**），即**分离轴定理**。

SAT 是一种用于判断凸几何体是否相交的经典方法。它将多维形状投影到一维数轴，通过寻找能够将两个形状完全分开的方向判定碰撞。

SAT 常用于：

- 二维凸多边形碰撞检测
- OBB 旋转包围盒检测
- 机器人足印与障碍物检测
- 路径规划中的几何相交测试
- 游戏物理
- 凸多面体碰撞检测

---

## 2. 分离轴定理

对于两个凸形状 $A$ 和 $B$：

> 如果它们不相交，则一定存在至少一条轴，使两个形状在该轴上的投影区间不重叠。

这条轴称为：

```text
Separating Axis
分离轴
```

因此：

```text
找到一条分离轴  -> 不碰撞
所有候选轴投影都重叠 -> 碰撞
```

---

## 3. 凸多边形

凸多边形满足：

> 多边形内任意两点之间的线段都完全位于多边形内部或边界上。

本项目要求顶点：

- 按顺时针或逆时针排列
- 至少包含 3 个顶点
- 相邻顶点不能重复
- 整体必须为凸多边形

`_validate_polygon()` 通过连续边的二维叉积符号检查凸性和顶点顺序。

---

## 4. 多边形的边

设多边形顶点为：

```math
\mathbf{v}_0,
\mathbf{v}_1,
\ldots,
\mathbf{v}_{N-1}
```

第 $i$ 条边为：

```math
\mathbf{e}_i
=
\mathbf{v}_{i+1}
-
\mathbf{v}_i
```

最后一个顶点的下一个顶点重新回到：

```math
\mathbf{v}_0
```

因此多边形边界形成闭环。

---

## 5. 候选分离轴

对于二维凸多边形，只需要检查两个多边形所有边的法向量。

设一条边为：

```math
\mathbf{e}
=
\begin{bmatrix}
e_x & e_y
\end{bmatrix}^T
```

一个与它垂直的法向量为：

```math
\mathbf{n}
=
\begin{bmatrix}
-e_y & e_x
\end{bmatrix}^T
```

将它归一化：

```math
\hat{\mathbf{n}}
=
\frac{\mathbf{n}}
{\lVert\mathbf{n}\rVert_2}
```

得到用于投影的单位轴。

---

## 6. 点在轴上的投影

点 $\mathbf{v}$ 在单位轴 $\hat{\mathbf{n}}$ 上的标量投影为：

```math
p
=
\mathbf{v}^T
\hat{\mathbf{n}}
```

对多边形的所有顶点进行投影，得到一维区间：

```math
P
=
[p_{\min},p_{\max}]
```

其中：

```math
p_{\min}
=
\min_i
(\mathbf{v}_i^T\hat{\mathbf{n}})
```

```math
p_{\max}
=
\max_i
(\mathbf{v}_i^T\hat{\mathbf{n}})
```

---

## 7. 投影区间分离

设两个多边形在某条轴上的投影为：

```math
A=[a_{\min},a_{\max}]
```

```math
B=[b_{\min},b_{\max}]
```

如果：

```math
a_{\max}<b_{\min}
```

或：

```math
b_{\max}<a_{\min}
```

则两个投影区间分离，当前轴就是分离轴。

此时可以立即返回：

```python
False
```

无需继续检查其余轴。

---

## 8. 投影重叠量

当两个区间相交时，沿当前轴将它们分开所需的最小移动量为：

```math
o
=
\min
\left(
a_{\max}-b_{\min},
b_{\max}-a_{\min}
\right)
```

这一形式不仅适用于普通部分重叠，也能处理一个投影区间完全包含另一个区间的情况。

---

## 9. 最小平移向量

如果所有候选轴上的投影都重叠，则两个凸多边形相交。

在所有重叠量中选择最小值：

```math
d
=
\min_k o_k
```

该轴的单位法向量记为：

```math
\mathbf{n}
```

则最小平移向量的大小为 $d$，方向由 $\mathbf{n}$ 给出。

程序将法向量统一调整为从多边形 $A$ 的中心指向多边形 $B$ 的中心。要将 $A$ 移出 $B$，通常可以沿反方向移动：

```math
-d\mathbf{n}
```

---

## 10. 边界接触

当两个多边形只在边或顶点上接触时，最小重叠深度为：

```math
d=0
```

本项目将这种边界接触视为碰撞，因此返回：

```python
True, normal, 0.0
```

`tolerance` 用于吸收浮点数计算中很小的投影误差。

---

## 11. 算法流程

SAT 的完整检测流程为：

```text
读取两个凸多边形
          ↓
生成所有边的单位法向量
          ↓
将两个多边形投影到当前轴
          ↓
投影是否分离？ ── 是 ─→ 不碰撞
          │
          否
          ↓
记录当前轴的重叠量
          ↓
检查完所有轴 ─→ 碰撞
```

## 13. 函数调用

```python
from sat import sat_collision

collision, normal, depth = sat_collision(
    polygon_a,
    polygon_b,
    tolerance=1e-10,
)
```

参数含义：

| 参数 | 含义 |
|---|---|
| `polygon_a` | 形状为 $N\times2$ 的第一个凸多边形 |
| `polygon_b` | 形状为 $M\times2$ 的第二个凸多边形 |
| `tolerance` | 用于边界比较的非负浮点容差 |

返回：

| 变量 | 含义 |
|---|---|
| `collision` | 是否相交或接触 |
| `normal` | 从 $A$ 指向 $B$ 的最小重叠轴，未碰撞时为 `None` |
| `depth` | 最小穿透深度，未碰撞时为 `0.0` |

## 14. 多边形顶点格式

一个逆时针矩形可以写为：

```python
polygon = np.array([
    [-1.0, -0.5],
    [1.0, -0.5],
    [1.0, 0.5],
    [-1.0, 0.5],
])
```

顶点不需要在末尾重复第一个顶点，程序会自动将最后一个顶点连回起点。

## 15. 计算复杂度

假设多边形 $A$ 有 $N$ 个顶点，$B$ 有 $M$ 个顶点。

候选轴数量为：

```math
N+M
```

每条轴需要投影两个多边形的所有顶点，因此朴素实现的时间复杂度约为：

```math
O((N+M)^2)
```

如果复用法向量、合并重复平行轴，或事先使用 AABB 排除分离物体，可以降低实际计算量。

---

## 16. 特点与局限

SAT 的优点是：

- 原理直观
- 对二维凸多边形容易实现
- 可以同时返回碰撞法向和穿透深度
- 能够正确处理旋转形状
- 发现任意分离轴后可立即结束

它的局限是：

- 直接适用于凸形状
- 凹多边形需要先分解为多个凸多边形
- 顶点数较多时投影计算量会增大
- 三维 SAT 还需要检查边叉乘产生的候选轴
- 完全包含且中心重合时，最小平移方向本身可能不唯一
