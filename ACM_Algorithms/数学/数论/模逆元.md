
#逆元
在数论中，逆元是一个非常重要的概念，它与模运算息息相关。
# 定义
给定一个正整数$m$，对于整数$a$，如果存在$x$使得$ax \equiv 1 \pmod{m}$，那么$x$就被称为$a$摸$m$的逆元，记为$a^{-1} \pmod m$。这里的$ax \equiv 1 \pmod{m}$表示$\mathcal{ax-1}$能被$\mathcal{m}$整除，即存在整数$k$使得$\mathcal{ax=km+1}$ 

# 作用
## 1. 模运算中的除法模拟
+ 在常规算术运算里，除法是乘法的逆运算。然而在模运算环境中，直接进行除法操作并不直观。但引入逆元概念后，可将模运算中的除法转化为乘法。
+ 例如，在模 $m$ 的运算体系下，若要计算 $b\div a\ (\text{mod}\ m)$(前提是 $a$ 模 $m$ 的逆元$a^{-1}$存在，即$\gcd(a, m)=1$），那么$b\div a\ (\text{mod}\ m)$就等价于$b\times a^{-1}\ (\text{mod}\ m)$。
+ 这种转化在密码学、数论算法以及组合数学等领域中，当处理涉及模运算的复杂表达式求值时极为关键。比如在 RSA 密码体制的某些计算环节中，就会利用逆元来完成模运算下的除法操作。

## 2. 求解线性同余方程
+ 对于线性同余方程$ax\equiv b\ (\text{mod}\ m)$，若 $a$ 模 $m$ 的逆元$a^{-1}$存在（即$\gcd(a, m)=1$），可在方程两边同时乘以$a^{-1}$，从而得到$x\equiv a^{-1}b\ (\text{mod}\ m)$，这就直接给出了同余方程的解。
+ 例如，求解同余方程$3x\equiv 2\ (\text{mod}\ 7)$。首先，因为$\gcd(3, 7)=1$，所以 $3$ 模 $7$ 的逆元存在。通过计算（如扩展欧几里得算法）可知 $3$ 模 $7$ 的逆元为 $5$（因为$3×5 = 15\equiv 1\ (\text{mod}\ 7)$），那么原方程的解就是$x\equiv 5×2\equiv 10\equiv 3\ (\text{mod}\ 7)$。

## 3. 计算组合数取模
**！！！！！！！！！！！！！！！！！！！！！重要！！！！！！！！！！！！！！！！！！！！！！！**

+ 在组合数学中，计算组合数$C(n, k)=\frac{n!}{k!(n - k)!}$ 并对某个数 $m$ 取模时，由于直接计算阶乘相除再取模会涉及到除法取模问题，此时逆元就派上用场。
+ 可以分别计算$k!(n - k)!$模$m$的逆元，然后将$n!$与这个逆元相乘并取模，就能得到$C(n, k)\ (\text{mod}\ m)$的结果。这种方法在解决一些与排列组合相关的计数问题且结果需要取模时非常有效，避免了直接计算大整数除法带来的困难和精度问题。
+ 对于整数 $a$ 和质数 $p$，若 $a$ 与 $p$ 互质（当 $p$ 为质数时，只要 $a$ 不是 $p$ 的倍数就互质），根据费马小定理，$a^{p - 1}\equiv1\pmod{p}$，那么 a 的逆元$a^{-1}\equiv a^{p - 2}\pmod{p}$。
+ 代码：

```cpp
//求快速幂
long long q_pow(long long base,long long power,long long mod){
    long long result = 1;
    while(power) {
        if (power & 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        power >>= 1;
    }
    return result;
}
//求x模mod的逆元，方便除法的取模运算
long long inv(long long x,long long mod){
    return q_pow(x,mod-2);
}
```

## 4. 密码学领域
+ 在公钥密码体制如 RSA 算法中，逆元起到了核心作用。RSA 算法的加密和解密过程基于大整数的模运算，其中私钥的计算就依赖于模逆元的求解。
+ 具体来说，在 RSA 算法中，通过选择两个大质数 $p$ 和 $q$，计算$n = pq$以及$\varphi(n)=(p - 1)(q - 1)$然后选择一个与$\varphi(n)$互质的整数 $e$ 作为公钥，通过计算 e 模$\varphi(n)$的逆元 $d$ 作为私钥。加密时使用公钥 $e$ 进行运算，解密时则使用私钥 $d$，这里的 $d$ 就是 $e$ 模$\varphi(n)$的逆元，保证了加密和解密操作的正确性和安全性。


# 逆元的求法

逆元都可以在 $O(\log n)$ 的时间复杂度内进行求解。
在这之前有一个前提，已知 $ax \equiv 1 \pmod p$ 里面的 $x$ 就是 $a^{-1}$ 模 $p$ 下的逆元，仅当 $\gcd(a,p) = 1$ 即 $a$ 和 $p$ 互素的时候逆元 $a^{-1} \mod p$ 存在，且在模 $p$ 的意义下是唯一的。
原因：
- 贝祖定理：方程 $ax+py=d$ 有整数解的**充要条件**是 $d$ 是 $gcd(a,p)$ 的倍数，这里 $d=1$，所以只有当 $gcd⁡(a,p)=1$ 时，才存在整数 $x,y$ 满足方程
- 反证法，假设有两个解 $x_1$ 和 $x_2$ 满足条件，两式子相减得到 $a(x_1 - x_2) \equiv 0 \pmod p$ ，已知 $\gcd(a,p) = 1$ 那么说明 $p \mid (x_1 - x_2)$ 即 $x_1 - x_2 \equiv 0 \pmod p$ 转化成 $x_1 \equiv x_2 \mod p$，即 $x_1$ 和 $x_2$ 在同一个等价类中，唯一。 

## 扩展欧几里得求解逆元

已知逆元的形式为 $ax \equiv 1 \pmod p$ ，这是一个线性同余方程，实际上也可以写成 $ax + bp = 1$ 的形式。那么我们就可以用[扩展欧几里](学习笔记/Algorithm/数学/数论/扩展欧几里得算法)得算法去求解这个 $x$。
这一个方法适合求出所有逆元存在的情形。

## 快速幂求解逆元

这一方法只适用于模数 $p$ 为素数的时候适用。
参考[[费马小定理 & 欧拉定理#费马小定理 | 费马小定理]]。由于 $a^{p - 1} \equiv 1 \pmod p$ 在 $p$ 为素数的情况下，那么转化为 $a * a^{p - 2} = a^{p-1} \equiv 1 \pmod p$ ，所以 $a^{p - 2} \equiv a^{-1} \pmod p$ ，因此可以直接使用快速幂求出 $a^{-1}$ 的逆元。

# 多个逆元的求法

有些场景下，需要快速处理出多个整数 $a_1,a_2,\cdots,a_n$ 在模 $m$ 意义下的逆元．此时，逐个求解逆元，总共需要 $O(n\log m)$ 的时间．实际上，如果将它们统一处理，就可以在 $O(n+\log m)$ 的时间内求出所有整数的逆元。

考虑序列 $\{a_i\}$ 的前缀积：
$$
T_0 = 1,~ T_i = a_iT_{i-1},~ i=1,2,\cdots,n.
$$
只要每个 $a_i$ 都与 $m$ 互素，它们的乘积 $S_n$ 就与 $m$ 互素。因此，可以通过前文所述算法求出 $S_n^{-1}\bmod m$ 的值。因为乘积的逆元就是逆元的乘积，所以，从 $S_n^{-1}$ 出发，反向遍历序列就能求出每个 $S_i$ 的逆元：
$$
T_{i-1}^{-1} = a_iT_i^{-1} \bmod m,~ i = n,n-1,\cdots,1.
$$
由此，单个 $a_i$ 的逆元可以通过下式计算：
$$
a_i^{-1} = T_{i-1}T_i^{-1} \bmod m,~ i = 1,2,\cdots,n.
$$
