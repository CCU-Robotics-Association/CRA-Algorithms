# 唯一分解定理(算术基本定理)
## 定义
唯一分解定理，也称为算术基本定理，是数论中的一个基本定理。它表明任何一个大于 $1$  的自然数 $N$ ，如果 $N$  不是质数，那么 $N$  可以唯一地分解成有限个质数的乘积，即$N=p_1^{a_1} \times p_2^{a_2} \times p_3^{a_3} \times \dots \times p_k^{}a_k$ ，其中$p_1 < p_2 < p_3 < \dots < p_k$ 且为质数，$a_1,a_2,a_3 \dots a_k$ 是正整数。
## 示例
例如，对于数字$12$ ，它可以分解成$2^2 \times 3^1$。其中$p_1 = 2,a_1 = 2,p_2 = 3,a_2 = 1$ ;
再如$30=2\times3\times5$ ,即$2^1\times3^1\times5^1$ ,这里$p_1=2,p_2=3,p_3=5,a_1=1,a_2=1,a_3=1$。
# 朴素求法
考虑朴素算法，因数是成对分布的，$N$ 的所有因数可以被分成两块，即 $[2, \sqrt N]$ 和 $[\sqrt N+1,N)$．只需要把 $[2, \sqrt N]$ 里的数遍历一遍，再根据除法就可以找出至少两个因数了．这个方法的时间复杂度为 $O(\sqrt N)$．
最简单的算法即为从 $[2, \sqrt N]$ 进行遍历。
```cpp
int n;
cin>>n;
vector<pair<int,int>> fac;
for (int i=2;i * i <= n; ++i) {
    if (n % i == 0) {
        int cnt = 0;
        while(n % i == 0) {
            cnt++;
            n /= i;
        }
        fac.emplace_back(i,cnt);
    }
}
if (n != 1) fac.emplace_back(n,1);
```
值得指出的是，如果开始已经打了一个素数表的话，时间复杂度将从 $O(\sqrt N)$ 下降到 $O(\frac {\sqrt{N}} {\ln N})$。
