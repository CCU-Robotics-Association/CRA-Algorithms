如果我们想要知道小于等于 n 有多少个素数呢？

一个自然的想法是对于小于等于 n 的每个数进行一次质数检验．这种暴力的做法显然不能达到最优复杂度。
# 埃拉托斯特尼筛法（埃氏筛）
对于任意一个大于 $1$ 的正整数 $n$，那么它的 $x$ 倍就是合数（$x > 1$）．利用这个结论，我们可以避免很多次不必要的检测．
如果我们从小到大考虑每个数，然后同时把当前这个数的所有（比自己大的）倍数记为合数，那么运行结束的时候没有被标记的数就是素数了．
```cpp
const int N = 1e6 + 5;
vector<int> fac; // 记录质数
vector<bool> flag(N); // 当前这个数有没有被筛掉
void init() {
    flag[1] = true;
    for (int i=2;i<N;++i) {
        if (!flag[i]) { // 没有被标记，说明是质数
	        // 从 i*i 开始，因为⼩于 i 的倍数已经被划掉了
            for (int j = i * i;j < N;j += i) flag[j] = true; // 筛掉这个质数的倍数
            fac.push_back(i);
        }
    }
}
```
时间复杂度为$O(n\log\log n)$。

>[!tip]-
>    现在我们就来看看推导过程：
>    如果每一次对数组的操作花费 1 个单位时间，则时间复杂度为：
>    $$O\left(\sum_{k=1}^{\pi(n)}{\frac{n}{p_k}}\right)=O\left(n\sum_{k=1}^{\pi(n)}{\frac{1}{p_k}}\right)$$
>    其中 $p_k$ 表示第 $k$ 小的素数，$\pi(n)$ 表示 $\le n$ 的素数个数。
>    
>    $\sum_{k=1}^{\pi(n)}$ 表示第一层 for 循环，其中累加上界 $\pi(n)$ 为 `if (prime[i])` 进入 true 分支的次数；$\frac{n}{p_k}$ 表示第二层 for 循环的执行次数．
>    根据 Mertens 第二定理，存在常数 $B_1$ 使得：
>    $$\sum_{k=1}^{\pi(n)}{\frac{1}{p_k}}=\log\log n+B_1+O\left(\frac{1}{\log n}\right)$$
>    
>    所以 **Eratosthenes 筛法** 的时间复杂度为 $O(n\log\log n)$．接下来我们证明 Mertens 第二定理的弱化版本 $\sum_{k\le\pi(n)}1/p_k=O(\log\log n)$：
>    根据 $\pi(n)=\Theta(n/\log n)$，可知第 $n$ 个素数的大小为 $\Theta(n\log n)$．于是就有$$\begin{aligned}\sum_{k=1}^{\pi(n)}{\frac{1}{p_k}}&=O\left(\sum_{k=2}^{\pi(n)}{\frac{1}{k\log k}}\right) \\&=O\left(\int_2^{\pi(n)}{\frac{\mathrm dx}{x\log x}}\right) \\&=O(\log\log\pi(n))=O(\log\log n)\end{aligned}$$
>    当然，上面的做法效率仍然不够高效，应用下面几种方法可以稍微提高算法的执行效率．

## 筛至平方根
显然，要找到直到 $n$ 为止的所有素数，仅对不超过 $\sqrt n$ 的素数进行筛选就足够了。
```cpp
const int N = 1e6 + 5;
const int MOD = 1e9 + 7;
vector<int> fac;
vector<bool> flag(N);
void init() {
    flag[1] = true;
    for (int i=2;i * i<N;++i) {
        if (!flag[i]) {
            for (int j = i + i;j < N;j += i) flag[j] = true;
            fac.push_back(i);
        }
    }
}
```
这种优化不会影响渐近时间复杂度，实际上重复以上证明，我们将得到 $O(n \ln \ln \sqrt n + o(n))$，根据对数的性质，它们的渐近相同，但操作次数会明显减少。

# 欧拉筛（线性筛）
埃氏筛法仍有优化空间，它会将一个合数重复多次标记．有没有什么办法省掉无意义的步骤呢？答案是肯定的。
我们的做法是，让每⼀个合数被它的最⼩质因数筛掉。
如果能让每个合数都只被标记一次，那么时间复杂度就可以降到 $O(n)$ 了。
```cpp
const int N = 1e6 + 5;
vector<int> fac;
vector<bool> flag(N);
void init() {
    flag[1] = true; // 如果没标记过，就是质数
    for (int i=2;i<N;++i) {
        if (!flag[i]) fac.push_back(i);
        for (const int& j : fac) {
            if (i * j >= N) break;
            flag[i * j] = true;
            if (i % j == 0) break;
            // i % j == 0，换言之，i 之前被 j 筛过了，也就是说 j 是 i 的最小质因子，由于 fac 里面质数是从小到大的，所以 i 乘上其他的质数的结果一定会被 j 的倍数筛掉，就不需要在这里先筛一次，所以这里直接 break 掉就好了。
            // 例如，当 i 为 4 时，fac 数组里面有[2,3]，如果不直接在 i 为 2 的时候 break 掉，那么对于 12 这个数字来说，最小质因子应该是 2，在 4 的时候会被筛掉，复杂度就不是O(n)了。
        }
    }
}
```
注意到筛法求素数的同时也得到了每个数的最小质因子。

其实之前我每太理解欧拉筛，因为有些反直觉。埃氏筛非常符合我的直觉，对于一个素数$p$直接枚举它所有的合数$2p,3p,4p\dots$。正是这样筛导致对于数字$12$来说，它会被$6 \times 2$筛一次又会被$4\times 3$筛一次，这就导致了多筛了一次，所以才有了$O(n\log{n}\log{n})$的复杂度。

而欧拉筛仅仅只有被最小的质数筛了一次。由于我们的$fac$数组是由小到大存储素数的，对于外循环$i$和内循环$j$来说，一共存在两种情况：
- **情况一 $i \% j \ne 0$**：由于$fac$中的$j$是从小到大枚举的，说明此时$i$的最小质因子比$j$大，那么对于$j\times i$的最小质因子就是$j$。
- **情况二 $i \% j = 0$**：这是一个拐点，一旦$i$能被$j$整除，说明现在$i$的最小质因子就是$j$，此时倘若不退出循环，当$j$继续往下走的时候，那么$i\times j$的最小质因子就不是$j$了，因为此时最小质因子在$i$里面，所以需要在$j$走到$i$的最小质因子的时候退出循环，这样就实现了$O(n)$的时间复杂度，不会出现多筛的情况。
