# 引入

> 「物不知数」问题：有物不知其数，三三数之剩二，五五数之剩三，七七数之剩二．问物几何？

即求满足以下条件的整数：除以 $3$ 余 $2$，除以 $5$ 余 $3$，除以 $7$ 余 $2$。
该问题最早见于《孙子算经》中，并有该问题的具体解法．宋朝数学家秦九韶于 1247 年《数书九章》卷一、二《大衍类》对「物不知数」问题做出了完整系统的解答．上面具体问题的解答口诀由明朝数学家程大位在《算法统宗》中给出：
> 三人同行七十希，五树梅花廿一支，七子团圆正半月，除百零五便得知．

$2\times 70+3\times 21+2\times 15=233=2\times 105+23$，故答案为 $23$．
# 定义

中国剩余定理 (Chinese Remainder Theorem, CRT) 可求解如下形式的一元线性同余方程组（其中 $n_1, n_2, \cdots, n_k$ 两两互质）：
$$
{\Large
\begin{cases}
x &\equiv a_1 \pmod {n_1} \\
x &\equiv a_2 \pmod {n_2} \\
  &\vdots \\
x &\equiv a_k \pmod {n_k} \\
\end{cases}
}
$$
# 过程

1.  计算所有模数的积 $n = \prod_{i = 1}^{k} n_i$；
2.  对于第 $i$ 个方程：
    - 计算 $m_i=\frac{n}{n_i}$；
    - 计算 $m_i$ 在模 $n_i$ 意义下的 [逆元](学习笔记/Algorithm/数学/数论/模逆元)  $m_i^{-1}$；
    - 计算 $c_i=m_im_i^{-1}$（**不要对 $n_i$ 取模**）。
3.  方程组在模 $n$ 意义下的唯一解为：$x=\sum_{i=1}^k a_ic_i \pmod n$．

模板如下：
```cpp
int exgcd(int a, int b, int& x, int& y) {
	if (!b) {
		x = 1;
		y = 0;
		return a;
	}
	int d = exgcd(b, a % b, x, y), x0 = x, y0 = y;
	x = y0;
	y = x0 - a / b * y0;
	return d;
}
int crt(const vector<int>& Remainer, const vector<int>& MODS) {
	assert(Remainer.size() == MODS.size());
	int n = Remainer.size() - 1, m = 1, res = 0;
	for (int i = 1; i <= n; ++i) m *= MODS[i];
	for (int i = 1; i <= n; ++i) {
		int a = m / MODS[i], b = MODS[i], x, y, d = exgcd(a, b, x, y);
		x = (x % MODS[i] + MODS[i]) % MODS[i];
		res = (res + Remainer[i] * a % m * x % m) % m;
	}
	return (int)res;
}
```

注意有些可能会超`long long`这个时候开`__int128_t`就行。时间复杂度 $O(n\log n)$

# 证明

中国剩余定理存在一个前提，即满足 $n_1,n_2,\dots,n_k$ 两两互质。
中国剩余定理的过程实际上是在构造一组基向量，满足 $c_i \equiv 1 \pmod{n_i}$ 和 $c_i \equiv 0 \pmod{n_j} (i \ne j)$即对于每个线性同余方程，当且仅当只有当前的 $n_i$ 取余为 $1$ 其他的模数取余的值均为 $0$ ，类似于[[线性基]]这个算法。
那么我们有了一组基向量，则 $${\Large x = \sum_{i = 1}^{k} a_ic_i}$$
那么对于其中任意的第 $j$ 个方程 
$$
{\Large
x \equiv \sum_{i = 1}^{k} a_ic_i \equiv a_jc_j + \sum_{i \ne j} a_ic_j \pmod{n_j}
}
$$
因为：
- $c_j \equiv 1 \pmod{n_j}$ 
- 同时，对于所有的 $i \ne j$ 的 $c_j \equiv 0 \pmod{n_j}$ 
所以：
$$
{\Large
x \equiv a_j \pmod{n_j}
}
$$
这就是我们想要的答案。
那么我们的 $c_i$ 该如何构造呢。
上文提到，我们需要构造一个基向量，满足 $c_i \equiv 1 \pmod{n_i}$ 和 $c_i \equiv 0 \pmod{n_j} (i \ne j)$ 。
而其中第二个要求比较好满足，要求$c_i \equiv 0 \pmod{n_j} (i \ne j)$ 那么我们只需要让 $c_i$ 为其他所有 $n_j$ 的倍数即可。
于是我们令 $n = \prod_{i = 1}^{k} n_i$ 同时 $m_i = \frac{n}{n_i}$ ，那么 $m_i$ 就是其他所有 $n_j$ 的倍数，让他成为 $c_i$ 的倍数即可，而对于第一个要求，我们需要找到一个 $x$ 使得 $m_i \times x \equiv 1 \pmod{n_i}$ ，那这不就是我们的[[模逆元]]吗，只需要再求得 $m_i^{-1}$ 在 $n_i$ 下的逆元即可，同时 $m_i^{-1}$ 必然存在，因为存在一个前提条件 $\gcd(m_i,n_i) = 1$ 。
最后，我们的式子为 $c_i = m_i \times m_i^{-1}$ ，注意这时候不能对 $n_i$ 取模。因为我们需要对 $n$ 取模才对。
对应到代码中：
```cpp
int a = m / MODS[i]; // 这个就是 m_i
int b = MODS[i]; // 这个就是 n_i
int x, y, d = exgcd(a, b, x, y);
x = (x % MODS[i] + MODS[i]) % MODS[i];
res = (res + Remainer[i] * a % m * x % m) % m;
```
变量对应关系为：
- `m`：所有模数的乘积 $n$ 
- `a`：$m_i = \frac{n}{n_i}$
- `b`：$n_i$
- `x`：$m_i^{-1} \pmod{n_i}$ 
- `Remainer[i] * a * x`：$a_i \cdot m_i \cdot m_i^{-1} = a_ic_i$
- `res`：累加得到
$$
{\Large
x = \sum_{i = 1}^{k} a_ic_i \pmod n
}
$$
例题：[P1495 【模板】中国剩余定理（CRT）/ 曹冲养猪 - 洛谷](https://www.luogu.com.cn/problem/P1495)

# 应用

很多数论题、计数题里，最终答案要对某个模数 $M$ 取模。
如果 $M$ 是质数，那很好办，因为质数模下有很多好性质，比如：
- 非零数都有逆元；
- 可以用费马小定理求逆元；
- 可以方便地做除法。
但如果 $M$ 不是质数，那么直接对 $M$ 取模就会遇到问题：
- 有些数没有逆元；
- 不能随便做除法；
- 很多质数模下的定理不能直接用。
不过，如果 $M$ 分解质因数后**没有平方因子**，也就是它是若干个互不相同的质数的乘积：
$${\Large M=p_1p_2\dots p_k}$$
其中 $p_i$ 是质数，且两两不同，那么 $p_1,p_2,…,p_k$​ 两两互质。
于是我们就可以这样做：
1. 把原问题在模 $p_1,p_2,…,p_k$​ 下分别计算；
2. 得到答案在这些小质数模下的余数；
3. 用中国剩余定理把这些余数合并成模 $M$ 下的唯一答案。

#  Garner 算法

CRT 的另一个用途是用一组比较小的质数表示一个大的整数。
例如，若 $a$ 满足如下线性方程，且 $a < \prod_{i=1}^{k} p_i$ (其中 $p_i$ 两两互质)：
$$
{\Large
\begin{cases}
a &\equiv a_1 \pmod {p_1} \\
a &\equiv a_2 \pmod {p_2} \\
  &\vdots \\
a &\equiv a_k \pmod {p_k} \\
\end{cases}
}
$$
我们就可以用如下的式子来表示 $a$ (混合进制转化)：
$$
{\Large
a = x_1 + x_2 p_1 + x_3 p_1 p_2 + \ldots + x_k p_1 \ldots p_{k-1}
}
$$
**Garner 算法** 将用来计算系数 $x_1, \ldots, x_k$。
令 $r_{ij}$ 为 $p_i$ 在模 $p_j$ 意义下的逆元，即满足 $p_i \cdot r_{i,j} \equiv 1 \pmod{p_j}$ 。
我们将混合表达式代入线性方程的第一个式子中，由于除了第一项以外，其他所有项都有 $p_1$ 所以得到第一个方程：$${\Large a_1 \equiv x_1 \pmod{p_1}}$$
代入第二个方程得到：$${\Large a_2 \equiv x_1 + x_2p_1 \pmod{p_2}}$$ 为了求出 $x_2$ 来进行化简 
$$
{\Large
\begin{aligned}
    a_2 - x_1           &\equiv x_2 p_1             &\pmod{p_2} \\
    (a_2 - x_1) r_{1,2} &\equiv x_2                 &\pmod{p_2} \\
    x_2                 &\equiv (a_2 - x_1) r_{1,2} &\pmod{p_2}
\end{aligned}
}
$$
那么类似的，我们就可以得出：$${\Large x_k=(\dots((a_k-x_1)r_{1,k}-x_2)r_{2,k})-\dots)r_{k-1,k} \bmod p_k}$$
```cpp
for (int i = 0; i < k; ++i) {
  x[i] = a[i];
  for (int j = 0; j < i; ++j) {
    x[i] = r[j][i] * (x[i] - x[j]);
    x[i] = x[i] % p[i];
    if (x[i] < 0) x[i] += p[i];
  }
}
```
时间复杂度为 $o(n^2\log n)$ 主要时间花费在得到 $r_{i,j}$ 上。

# 扩展中国剩余定理（EXCRT）

中国剩余定理的局限性在于必须要求 $n_i,n_j$ 两两互质，而扩展中国剩余定理就是为了解决这样的情况的。
扩展中国剩余定理的过程是两两合并，直到只剩下一个方程。
式子中 $n_i,n_j$ 不满足两两互质。
$$
{\Large
\begin{cases}
x &\equiv a_1 \pmod {n_1} \\
x &\equiv a_2 \pmod {n_2} \\
  &\vdots \\
x &\equiv a_k \pmod {n_k} \\
\end{cases}
}
$$
由第一个方程可设： $${\Large x = a_1 + n_1k_1}$$
代入第二个方程：$${\Large a_1 + n_1k_1 \equiv a_2 \pmod{n_2}}$$
移项得：$${\Large n_1k_1 \equiv a_2 - a_1 \pmod{n_2}}$$
令 $d = \gcd(n_1,n_2)$ ，那么这一个同余方程必然满足 $d | (a_2 - a_1)$ 如果不满足，则方程无解。
两边同时除以 $d$ ：$${\Large \frac{n_1}{d}k_1 \equiv \frac{a_2 - a_1}{d} \pmod{\frac{n_2}{d}}}$$
因为 $\gcd(\frac{n_1}{d},\frac{n_2}{d}) = 1$ ，所以 $\frac{n_1}{d}$ 在 $\frac{n_2}{d}$ 下存在逆元，那么移相之后得到：$${\Large k_1 \equiv \frac{a_2 - a_1}{d} \cdot (\frac{n_1}{d})^{-1} \pmod{\frac{n_2}{d}}}$$ 我们令$\alpha_1 = \frac{a_2 - a_1}{d} \cdot (\frac{n_1}{d})^{-1}$ ，那么显然，$\alpha_1$ 为 $k_1$ 的一个特解，通解为： $${\Large k_1 = \alpha_1 + t \cdot \frac{n_2}{d},t\in \mathbb{Z}}$$ 我们把得出来的 $k_1$ 代入到设的第一个方程 $${\Large x = a_1 + n_1 \cdot \alpha_1 + t\cdot \frac{n_1n_2}{d}}$$ 令 $M = lcm(n_1,n_2) = \frac{n_1n_2}{d}$ ，那么原式子可以转化为 $${\Large x \equiv a_1 + n_1 \cdot \alpha_1 \pmod{M}}$$这样就实现了两个式子的合并，然后继续向下合并即可。
我们以例题[P4777 【模板】扩展中国剩余定理（EXCRT） - 洛谷](https://www.luogu.com.cn/problem/P4777)为例。
主要代码如下：

```cpp
int lcm(int a,int b) {return a / __gcd(a,b) * b;}
int exgcd(int a,int b,int& x,int& y) {
	if (!b) {
		x = 1;
		y = 0;
		return a;
	}
	int d = exgcd(b,a%b,x,y),x0 = x,y0 = y;
	x = y0;
	y = x0 - a / b * y0;
	return d;
}
// Remainer为余数，MODS为模数
int EXCRT(const vector<int>& Remainer,const vector<int>& MODS) {
	assert(Remainer.size() == MODS.size());
	int n = Remainer.size() - 1,ans = Remainer[1],M = MODS[1];
	for (int i = 2;i <= n;++i) {
		int a2 = Remainer[i],m2 = MODS[i];
		int d = __gcd(M,m2);
		if ((a2 - ans) % d) return -1;
		int a = M / d,b = m2 / d,x,y;
		exgcd(a,b,x,y);
		x = (x % b + b) % b;
		i128 k1 = ((i128)a2 - ans) / d * x % b,temp = ans + M * k1;
		M = lcm(M,m2);
		ans = (temp % M + M) % M;
	}
	return ans;
}
```
