# 前言
`bitset` 是 C++ 标准库中一个强大的模板类，专门用于高效处理固定大小的位序列（二进制位）。在算法竞赛中，它常用于位操作优化、状态压缩和布尔数组的高效处理。

# 基本概念
`bitset` 是用于存储二进制位的一个模板，它的特征如下：

+ **固定大小**：在编译时确定位数（N）
+ **高效位操作**：支持各种位运算（与、或、异或等）
+ **内存紧凑**：每个元素仅占 1 位（8个元素=1字节）
+ **边界安全**：访问时进行边界检查（可禁用）

## 声明与初始化
```cpp
    // 声明一个8位的bitset（所有位初始为0）
    bitset<8> bs1;  
    // 用整数初始化（二进制表示）
    bitset<8> bs2(15);  // 00001111
    // 用字符串初始化
    bitset<8> bs3("10101010");  // 10101010
	// 混合初始化
	bitset<8> bs4("1010", 3);  // 从字符串前3位初始化：00000101
```

# 核心操作
接下来以创建的这个`bitset`为例

```cpp
bitset<8> bs("11001100");
```

**！！！！！注意**：对于bitset来说，在它创建的时候**长度固定**，所以**不存在增、删**的操作，只有**查和改**。

## 访问（查）
bitset类型的数据和vector一样，都是使用下标（索引）进行对值的访问

```cpp
bitset<8> bs("11001100");
// 使用下标访问（从右向左，索引0是最低位）
bs[0] = 1;     // 修改最低位：11001101
bool bit = bs[3];  // 获取第3位（从0计）-> 1
bs.count();     // 返回1的个数
bs.any();       // 是否有至少一个1
bs.none();      // 是否全为0
bs.all();       // 是否全为1（C++11+）
bs.test(3);     // 检查第3位是否为1
```

## 修改
```cpp
bitset<8> bs("11001100");
bs.set(2, 0);   // 设置第2位为0：11001000
bs.flip(5);     // 翻转第5位：11101000
bs.reset(7);    // 设置第7位为0：01101000
bs.set();       // 所有位置1：11111111
bs.reset();     // 所有位置0：00000000
bs.flip();      // 所有位取反：00000000 -> 11111111
```

## 类型转换
```cpp
bitset<8> bs("11001100");
string s = bs.to_string();  // 转为字符串："00001001"
unsigned long ul = bs.to_ulong();  // 转为无符号长整型
unsigned long long ull = bs.to_ullong();  // C++11+
```

## 位运算
```cpp
bitset<8> a("11001100");
bitset<8> b("00110011");
a & b;   // 按位与：00000000
a | b;   // 按位或：11111111
a ^ b;   // 按位异或：11111111
~a;      // 按位取反：00110011
a << 2;  // 左移2位：00110000
b >> 3;  // 右移3位：00000110
```
